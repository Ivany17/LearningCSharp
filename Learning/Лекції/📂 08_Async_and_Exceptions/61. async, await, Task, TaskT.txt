Тема №61: Асинхронне програмування (Async/Await) ⏳
Уяви, що ти готуєш вечерю 🍲. Тобі потрібно закип'ятити воду для макаронів і нарізати овочі.

🟡 Синхронний підхід: Ти ставиш каструлю на вогонь і стоїш біля неї 5 хвилин, нічого не роблячи, поки вона не закипить. 
Тільки потім починаєш різати овочі. Це марна трата часу!

🟢 Асинхронний підхід: Ти ставиш каструлю, вмикаєш вогонь і, поки вода гріється сама по собі, ти спокійно ріжеш овочі. 
Ти не чекаєш "застигши", ти робиш іншу роботу, поки виконується тривалий процес.

В програмуванні "кип'ятіння води" — це довгі завдання: завантаження файлу з інтернету, запис великої бази даних або очікування відповіді від сервера. 
Асинхронність дозволяє програмі не "зависати", а залишатися чуйною.

🔑 Основні поняття:
Task 📦 — це об'єкт, який представляє роботу, що виконується. Можна уявити це як "обіцянку", що робота буде зроблена і колись поверне результат.
async ⚡ — це модифікатор, який ти додаєш до методу. Він каже компілятору: "Увага, всередині цього методу може бути асинхронне очікування!".
await 🛑 — це команда "зачекай тут". Коли програма бачить await, вона каже: "Я піду зроблю щось інше, а коли ця конкретна задача (Task) завершиться, 
я повернуся сюди і піду далі за кодом".

Щоб створити асинхронний метод, нам потрібно змінити три речі у порівнянні зі звичайним методом:

1️⃣. Модифікатор async
Він ставиться перед типом повернення. Це сигнал для компілятора: "Цей метод особливий, він вміє чекати".

Було: static void MyMethod()
Стало: static async Task MyMethod()

2️⃣. Тип повернення Task
В асинхронному світі ми рідко використовуємо void.
Якщо метод нічого не повертає, ми пишемо Task.
Якщо метод має повернути, наприклад, число int, ми пишемо Task<int>.
Це як "квиток" на отримання результату в майбутньому.

3️⃣. Ключове слово await
Це найголовніше. Воно ставиться тільки всередині async методів перед задачами, які потребують часу. 
Коли програма бачить await, вона не "зависає", а просто запам'ятовує місце, де зупинилася, і йде займатися іншими справами, поки задача не виконається.

⚡ Як викликати такий метод у Top-level statements?
Оскільки твій файл Program.cs підтримує сучасний синтаксис, ти просто пишеш:
await НазваМетоду();
Це змусить головну програму дочекатися завершення твоєї асинхронної задачі.

📝 Завдання №61: "Електронний чайник" ☕
Давай створимо програму, яка імітує роботу чайника.
Створи асинхронний метод BoilWaterAsync() (пам'ятай про async та повернення типу Task і що в асинхронних методах прийнято додавати слово Async у назву).
Всередині методу виведи повідомлення: "Чайник увімкнено...".
Використай await Task.Delay(3000);, щоб імітувати 3 секунди кипіння.
Після очікування виведи: "Чайник закипів! Можна пити чай.".
Виклич цей метод у своєму Program.cs.

✅ Рішення:
//У файлі Program.cs
using System;                         // Core Essentials (Console, Basic types)
using System.Threading.Tasks;         // Async

async Task BoilWaterAsync(){
    Console.WriteLine("Чайник увімкнено...");
    await Task.Delay(3000);
    Console.WriteLine("Чайник закипів! Можна пити чай.");
}

await BoilWaterAsync();

📝 Завдання №61.2: "Сніданок програміста" 🍳
Уяви, що поки чайник кипить, ти хочеш зробити щось корисне, наприклад, "почитати документацію".
Залиш свій метод BoilWaterAsync.
Додай у Program.cs (вище або нижче, як тобі зручно) звичайний вивід тексту: Console.WriteLine("Я читаю документацію, поки чекаю...");.
Експеримент: Спробуй спочатку викликати метод чайника БЕЗ ключового слова await (просто BoilWaterAsync();), 
а наступним рядком виведи текст про документацію.
Потім додай await назад і подивись, як зміниться порядок виводу в консолі.

✅ Рішення:
await BoilWaterAsync();
Console.WriteLine("Я читаю документацію, поки чекаю...");

async Task BoilWaterAsync(){
    Console.WriteLine("Чайник увімкнено...");
    await Task.Delay(3000);
    Console.WriteLine("Чайник закипів! Можна пити чай.");
}

📝 Завдання №61.3: "Справжня багатозадачність" 🔄
Давай змусимо програму працювати паралельно:
У Program.cs створи змінну: Task boilingTask = BoilWaterAsync(); (без await на початку рядка!). Це запустить чайник.
Наступним рядком виведи: Console.WriteLine("Я читаю документацію...");.
А ось тепер, на самому останньому рядку, напиши: await boilingTask;. Це гарантує, що програма не закриється, поки чайник не докипить.

✅ Рішення:
Task boilingTask = BoilWaterAsync();
Console.WriteLine("Я читаю документацію, поки чекаю...");
await boilingTask;

async Task BoilWaterAsync(){
    Console.WriteLine("Чайник увімкнено...");
    await Task.Delay(3000);
    Console.WriteLine("Чайник закипів! Можна пити чай.");
}

📝 Завдання №61.4: "Який чай будемо пити?" 🍵
Давай модифікуємо твій код, щоб метод не просто "кип'ятив", а "готував" конкретний напій.
Зміни метод BoilWaterAsync так, щоб він тепер називався MakeTeaAsync.
Метод повинен приймати параметр string teaType (наприклад, "Чорний" або "Зелений").
Зміни тип повернення методу з Task на Task<string>.
Після завершення Task.Delay(3000), метод повинен повернути рядок: return $"Ваш {teaType} чай готовий!";.
У основному коді виклич цей метод, передавши назву чаю.
Збережи результат виконання у змінну та виведи її в консоль (пам'ятай, що await тепер поверне тобі готовий рядок).

✅ Рішення:
string result = await MakeTeaAsync("чорний чай");
Console.WriteLine(result);

async Task<string> MakeTeaAsync(string teaType){
    Console.WriteLine("Чайник увімкнено...");
    await Task.Delay(3000);
    return $"Ваш {teaType} чай готовий!";
}

📝 Завдання №61.5: "Система оновлення гри" 🎮
Уяви, що ти пишеш лаунчер для гри. Тобі потрібно асинхронно перевірити наявність оновлень на сервері.
Твої кроки:
Створи асинхронний метод з назвою CheckForUpdatesAsync.
Параметр: Метод повинен приймати ім'я користувача (string playerName).
Тип повернення: Метод має повертати ціле число (int) — це буде розмір оновлення в мегабайтах. Отже, тип повернення має бути Task<int>.
Логіка всередині:
Виведи повідомлення: "Вітаємо, {playerName}! Шукаємо оновлення для вас...".
Зроби паузу в 4 секунди (Task.Delay), імітуючи запит до сервера.
Після паузи поверни (return) випадкове число від 100 до 1000 (використай клас Random).
Виклик у Program.cs:
Виклич цей метод, передавши туди своє ім'я.
Обов'язково використай await, щоб отримати число.
Виведи фінальний результат у консоль у форматі: "Оновлення знайдено! Розмір: {result} МБ.".

✅ Рішення:
int result = await CheckForUpdatesAsync("Ivan");
Console.WriteLine($"Оновлення знайдено! Розмір: {result} МБ.");

async Task<int> CheckForUpdatesAsync(string playerName)
{
    Random generator = new Random(); // обов'язково створюємо Random в середині методу, а не поза ним
    int number = generator.Next(100, 1001);
    Console.WriteLine($"Вітаємо, {playerName}! Шукаємо оновлення для вас...");
    await Task.Delay(4000);
    return number; 
}

📝 Завдання №61.6: "Вхід до бункера"
Уяви, що ти пишеш програму для термінала безпеки.
Метод: Створи асинхронний метод AuthenticateUserAsync.
Параметри: Він повинен приймати два рядки: string username та string password.
Тип повернення: Task<bool>.
Логіка всередині:
Виведи повідомлення: "Система: Перевірка доступу для {username}...".
Затримка: await Task.Delay(2500); (імітація зв'язку з базою даних).
Перевірка: Якщо password дорівнює "Admin123", метод повертає true, інакше — false.
Основний код (Top-level):
Виведи: "Введіть пароль:".
Створи змінну userPassword і запиши туди введення користувача через Console.ReadLine().
Виклич метод: Передай туди своє ім'я "Ivan" та введений пароль. Обов'язково використай await, 
щоб отримати результат (true або false) у змінну (наприклад, bool isAccessGranted).
Використовуй if/else, щоб вивести фінальне повідомлення залежно від результату: "Доступ дозволено!" або "Помилка! Доступ заборонено!".

✅ Рішення:
Console.WriteLine("Введіть пароль:");
string userPassword = Console.ReadLine() ?? "";
bool isAccessGranted = await AuthenticateUserAsync("Ivan", userPassword);
if (isAccessGranted)
{
    Console.WriteLine("Доступ дозволено!");
} else
{
    Console.WriteLine("Помилка! Доступ заборонено!");
} 

async Task<bool> AuthenticateUserAsync(string username, string password)
{
    Console.WriteLine($"Система: Перевірка доступу для {username}...");
    await Task.Delay(2500);
    if(password == "Admin123")
    {
        return true;
    } return false;
}
