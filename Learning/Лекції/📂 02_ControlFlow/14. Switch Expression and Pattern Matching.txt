Тема №14: Switch Expression та Pattern Matching
1. Switch Expression (Вираз switch)
Це еволюція класичного switch. Якщо раніше switch був командою (виконував дії), то тепер він став виразом — 
тобто він обчислює і одразу повертає значення.

Головні відмінності від класичного switch:
Синтаксис: Змінна стоїть перед словом switch.
Стрілки: Замість case: та break; ми використовуємо =>.
Default: Замість default: використовується символ підкреслення _ (discard pattern).

Компактність: Весь блок — це одна команда, що закінчується ;.

2. Pattern Matching (Зіставлення зі зразком)
Це здатність switch перевіряти не тільки рівність (==), а й складні умови:
Relational patterns: Перевірка діапазонів (> 10, <= 100).

Logical patterns: Комбінування умов через and, or, not.

📝 Завдання №1: "Статус замовлення" (Switch Expression)
Умова:
Створи змінну int status = 2;.
Напиши Switch Expression, який записує у змінну string message наступне:
1 => "Замовлення прийнято"
2 => "В дорозі"
3 => "Доставлено"
_ => "Статус невідомий"
Виведи message в консоль.

✅ Рішення:
int status = 2;
string message = status switch
{
    1 => "Замовлення прийнято",
    2 => "В дорозі",
    3 => "Доставлено",
    _ => "Статус невідомий"
};
Console.WriteLine(message); // В дорозі

📝 Завдання №2: "Оцінка температури" (Pattern Matching)
Умова:
Створи змінну int temp = 25;.
Напиши Switch Expression, який визначає стан води за температурою:
< 0 => "Лід"
0 or > 0 and < 100 => "Рідина" (тут використай ключові слова and / or)
>= 100 => "Пара"
_ => "Невідомий стан"

✅ Рішення:
int temp = 25;
string status = temp switch
{
    < 0 => "Лід",
    >= 0 and < 100 => "Рідина", // тут використай ключові слова and / or
    >= 100 => "Пара",
};

Console.WriteLine(status);

📝 Завдання №3: Рефакторинг калькулятора через Switch Expression
Твоя мета — переписати логіку вибору операції. Тепер замість того, щоб виконувати дії (Console.WriteLine) 
всередині кожного case, твій switch має просто повернути результат обчислення у змінну.

Умови:
Використовуй свій вчорашній код як базу (ввід двох чисел num1, num2 та вибору choice).
Створи змінну double result.
Присвой їй значення за допомогою Switch Expression.
Виведи фінальний результат у консоль один раз після всього блоку switch.

✅ Рішення:
Console.WriteLine("Введіть перше число");
double num1 = double.Parse(Console.ReadLine()!);
Console.WriteLine("Введіть друге число");
double num2 = double.Parse(Console.ReadLine()!);
Console.WriteLine("Виберіть дію: \n1 - Додавання \n2 - Віднімання \n3 - Множення \n4 - Ділення");
int choiсe = int.Parse(Console.ReadLine()!);

double result = choiсe switch
{
    1 => num1 + num2,
    2 => num1 - num2,
    3 => num1 * num2,
    4 => num1 / num2,
    _ => 0
};

Console.WriteLine($"Результат: {result}");


📝 Завдання 4: "Розумний конвертер валют"
Уяви, що ти пишеш термінал для обміну валют. 
У тебе є сума в гривнях (UAH), і користувач хоче конвертувати її в іншу валюту, але курс залежить від суми 
(чим більше міняєш — тим вигідніший курс).
Умови:
Користувач вводить суму в гривнях (double uah).
Користувач вводить код валюти (string currency): "USD", "EUR", або "PLN".
Створи змінну double result, яка через Switch Expression порахує кінцеву суму за такими правилами:
Валюта Сума (uah) Курс (1 одиниця валюти коштує...) 
USD Будь-яка 40.0 грн 
EUR < 1000 44.0 грн 
EUR >= 1000 43.5 грн (оптова ціна)
PLN Будь-яка 10.0 грн

✅ Рішення:
Console.WriteLine("Введіть вашу суму в гривнях (UAH)");
double uah = double.Parse(Console.ReadLine()!);
Console.WriteLine("Введіть код валюти, на яку ви хочете поміняти гроші: 'USD', 'EUR', 'PLN'");
string currency = Console.ReadLine()!;

var result = (currency, uah) switch
{
    ("USD", _) => uah / 40.0,
    ("EUR", < 1000) => uah / 44.0,
    ("EUR", >= 1000) => uah / 43.5,
    ("PLN", _) => uah / 10.0,
    _ => 0
};

Console.WriteLine($"{result:F2}");
