Тема №15: Pattern Matching — Перевірка типів (Type Patterns)
Це одна з найпотужніших фішок switch. Він може перевіряти не лише числа, а й те, що це за об'єкт.

Теорія:
За допомогою ключового слова is або просто вказуючи тип у switch, ми можемо розпізнати тип об'єкта та одразу дати йому тимчасове ім'я для роботи.


Приклад:
object data = 42;

string result = data switch
{
    int i => $"Це ціле число: {i}",
    string s => $"Це рядок довжиною {s.Length}",
    _ => "Невідомий тип"
};

Тобто, object — це "коробка", в яку можна покласти що завгодно (число, текст, об'єкт).
int i => ... — це команда: "Якщо в коробці int, дістань його і назви i".
Гнучкість: Це дозволяє писати один метод, який вміє обробляти різні типи даних, не "ламаючись".

📝 Завдання №1: "Універсальний обробник"
Давай створимо логіку, яка імітує обробку різних вхідних даних.

Твої дані:
object input = "Hello C#"; // Спробуй потім змінити на 100 або true

Твоє завдання:
Напиши Switch Expression для змінної input.
Оброби такі випадки:
Якщо це int — поверни рядок "Число: [значення], квадрат = [значення * значення]".
Якщо це string — поверни рядок "Текст: [значення], великими літерами: [значення.ToUpper()]".
Якщо це bool — поверни рядок "Логічне значення: [значення]".
Для всього іншого — "Тип не підтримується".
Виведи результат у консоль.

✅ Рішення:
object input = "Hello C#";
string result = input switch
{
    int i => $"Число: {i}, квадрат = {i * i}",
    string s => $"Текст: {s}, великими літерами: {s.ToUpper()}",
    bool b => $"Логічне значення: {b}",
    _ => "Тип не підтримується"
};
Console.WriteLine(result); // Текст: Hello C#, великими літерами: HELLO C#


📝 Завдання №2: "Розумний обробник повідомлень"
Уяви, що твоя програма отримує різні дані, і залежно від того, що це (текст, число чи взагалі порожнеча), вона має реагувати по-різному.
Твої дані:
object incomingData = 15; // Спробуй потім змінити на "Привіт", null або 0

Твоє завдання:
Напиши Switch Expression, який обробить incomingData за такими правилами:
Число 0: Якщо це int і він дорівнює 0 — поверни "Нуль - це теж число".
Додатне число: Якщо це int і він > 0 — поверни "Отримано число: [значення]".
Від'ємне число: Якщо це int і він < 0 — поверни "Від'ємне значення".
Текст: Якщо це string — поверни "Текст довжиною [s.Length] символів".
Порожнеча: Якщо дані null — поверни "Дані відсутні".
Все інше: "Невідомий формат".

✅ Рішення:
object incomingData = 15;

var result = incomingData switch
{
    int i when i == 0 => $"Нуль - це теж число",
    int i when i > 0 => $"Отримано число: {i}",
    int i when i < 0 => $"Від'ємне значення",
    string s => $"Текст довжиною {s.Length} символів",
    null => $"Дані відсутні",
    _ => "Невідомий формат"
};
Console.WriteLine(result); // Отримано число: 15

🛠 Завдання №3: "Розумний валідатор посилок"
Уяви, що ти пишеш логіку для поштомата. Система отримує об'єкт cargo, і ми не знаємо наперед, що це — вага (число) чи опис (рядок).
Твоя задача:
Створи змінну object cargo.
Використовуючи Switch Expression та Type Patterns з when, поверни статус посилки (string):
Якщо це int або double і значення > 30 — "Помилка: занадто важка посилка для поштомата".
Якщо це int або double і значення <= 30 — "Вага прийнята: [значення] кг".
Якщо це string і довжина тексту > 100 — "Помилка: занадто довгий опис".
Якщо це string і довжина <= 100 — "Опис прийнято: [текст]".
Якщо це bool — "Помилка: логічний тип не підтримується для вантажу".
Для всього іншого — "Тип вантажу не розпізнано".

✅ Рішення:
object cargo = true;

string result = cargo switch
{
    int i when i > 30 => $"Помилка: занадто важка посилка для поштомата",
    double d when d > 30 => $"Помилка: занадто важка посилка для поштомата",
    int i when i <= 30 => $"Вага прийнята: {i} кг",
    double d when d <= 30 => $"Вага прийнята: {d} кг",
    string s when s.Length > 100 => $"Помилка: занадто довгий опис",
    string s when s.Length <= 100 => $"Опис прийнято: {s}",
    bool b => $"Помилка: логічний тип не підтримується для вантажу",
    _ => $"Тип вантажу не розпізнано"
};

Console.WriteLine(result);
