Тема №17: Випадкові числа (Generating Random Numbers) 🎲
Іноді нам потрібно, щоб програма сама обрала число. Наприклад, для гри в кості, лотереї або щоб комп'ютер "загадав" число.

Для цього в C# є спеціальний інструмент — об'єкт Random.

Як це працює:
Спочатку ми створюємо "генератор":
Random generator = new Random();

Потім просимо його дати нам число в певному діапазоні:
int number = generator.Next(1, 11);

Важливо: Команда Next(1, 11) видасть число від 1 до 10. Останнє число (11) не враховується. Це як відкритий інтервал у математиці.

📝 Завдання №17:
Давай створимо гру "Магічна куля".
Створи генератор випадкових чисел.
Нехай він згенерує число від 1 до 4 (тобто у Next() треба написати від 1 до 5).
Використай конструкцію if-else if-else (це коли багато умов підряд), щоб вивести передбачення:
Якщо випало 1 — "Так, обов'язково!"
Якщо випало 2 — "Ні, навіть не думай."
Якщо випало 3 — "Можливо, спробуй пізніше."
Якщо випало 4 — "Сьогодні твій щасливий день!"

⚠️ Підказка, як писати багато умов:
if (num == 1) { ... }
else if (num == 2) { ... }
else if (num == 3) { ... }
else { ... } // для останнього випадку

✅ Рішення:
Random generator = new Random();
int number = generator.Next(1, 5);

if(number == 1)
{
    Console.WriteLine("Так, обов'язково!");
} else if(number == 2)
{
    Console.WriteLine("Ні, навіть не думай.");
} else if(number == 3)
{
    Console.WriteLine("Можливо, спробуй пізніше.");
} else
{
    Console.WriteLine("Сьогодні твій щасливий день!");
}

📝 Завдання: "Гра в кубики":
Створи генератор випадкових чисел.
Згенеруй два числа (ніби кидаєш два кубики) від 1 до 6.
Виведи результат кожного кубика.
За допомогою Switch Expression виведи особливе повідомлення:
Якщо випало два однакових числа (дубль) => "Ого! Дубль: [число]!"
Якщо сума чисел більше 10 => "Високий результат!"
В усіх інших випадках => "Просто кидок".

✅ Рішення:
Console.WriteLine("Кидайте ваші кубики!");
Random generator = new Random();
int dice1 = generator.Next(1, 7);
Console.WriteLine(dice1);
int dice2 = generator.Next(1, 7);
Console.WriteLine(dice2);

string result = (dice1, dice2) switch
{
    (var a, var b) when a == b => $"Ого! Дубль: {dice1 + dice2}!",
    (var a, var b) when a + b > 10 => $"Високий результат!",
    _ => $"Просто кидок"
};
Console.WriteLine(result);

📝 Завдання: "Система безпеки (генератор паролів)"
Уяви, що ти пишеш частину коду для створення тимчасових PIN-кодів.

Твоя задача:
Створи генератор випадкових чисел.
Згенеруй три числа (назви їх digit1, digit2, digit3) у діапазоні від 0 до 9.
(Підказка: згадай про особливість верхньої межі в методі .Next()).
Виведи ці три цифри в один рядок, щоб вони виглядали як код (наприклад, 4-0-7).
Використовуючи Switch Expression, створи змінну string securityLevel, яка оцінить цей "пароль":
Якщо всі три цифри однакові (наприклад, 5, 5, 5) => "Максимальний ризик: однаковий код!"
Якщо цифри йдуть по порядку (наприклад, 1, 2, 3 або 7, 8, 9) => "Небезпечно: послідовний код!"
Якщо сума всіх трьох цифр менша за 5 => "Слабкий пароль: занадто малі цифри".
В усіх інших випадках => "Пароль прийнято".

✅ Рішення:
Random generator = new Random();
int digit1 = generator.Next(1, 10);
int digit2 = generator.Next(1, 10);
int digit3 = generator.Next(1, 10);
Console.WriteLine($"{digit1}-{digit2}-{digit3}");

string securityLevel = (digit1, digit2, digit3) switch
{
    (var a, var b, var c) when a == b && b == c  => $"Максимальний ризик: однаковий код!",
    (var a, var b, var c) when a == b + 1 && b == c + 1 => $"Небезпечно: послідовний код!",
    (var a, var b, var c) when b == a + 1 && c == b + 1 => $"Небезпечно: послідовний код!",
    (var a, var b, var c) when a + b + c < 5 => $"Слабкий пароль: занадто малі цифри",
    _ => $"Пароль прийнято"
};

Console.WriteLine(securityLevel);
