🧮 Тема №16: Клас Math у C#
1. 📏 Math.Abs(x)
Повертає модуль числа (число без знака мінус). Корисно, коли тобі треба знайти відстань або різницю, і неважливо, яке число було більшим.
Math.Abs(-5) → 5

2. 🔼 Math.Pow(base, exp)
Підносить число до степеня. Важливо: повертає тип double.
Math.Pow(2, 3) → 8 (2 в кубі)

3. 🌿 Math.Sqrt(x)
Обчислює квадратний корінь числа.
Math.Sqrt(16) → 4

4. 🏔️ Math.Max(x, y)
Порівнює два числа і повертає найбільше з них. Замінює довгу конструкцію if (a > b).
Math.Max(10, 20) → 20

5. 🌊 Math.Min(x, y)
Навпаки — повертає найменше з двох чисел.
Math.Min(10, 20) → 10

6. 🎯 Math.Round(x)
Округлення до найближчого цілого.
Math.Round(3.4) → 3
Math.Round(3.6) → 4

Примітка: В C# за замовчуванням діє "банківське округлення" (2.5 стане 2, а 3.5 стане 4 — до найближчого парного).

7. 🧱 Math.Floor(x)
Округлення "до підлоги" — завжди в меншу сторону.
Math.Floor(3.9) → 3
Math.Floor(-3.1) → поверне -4 (бо "підлога" для -3.1 — це наступне менше ціле число, тобто -4).

8. ☁️ Math.Ceiling(x)
Округлення "до стелі" — завжди в більшу сторону.
Math.Ceiling(3.1) → 4

9. ✂️ Math.Truncate(x)
Просто відкидає дробову частину, не округлюючи нікуди.
Math.Truncate(7.99) → 7
Math.Truncate(-3.9) → поверне -3 (просто "відрізає" хвіст).

10. 🔄 Math.Sign(x)
Показує знак числа. Повертає 1 (якщо додатне), -1 (якщо від'ємне) або 0. Дуже зручно для логіки в іграх або фізиці.

11. Math.PI та Math.E — це не методи, а константи.Тобі не треба пам'ятати, що $\pi \approx 3.14159...$, ти просто пишеш Math.PI.

📝 Завдання №1 (Округлення):
Повернися до свого конвертера валют (там, де UAH, USD, EUR).
Додай до фінального виводу метод Math.Round(результат, 2).
Запусти програму і подивись, як зміниться вивід для EUR.
Питання на засипку: Спробуй ввести суму, яка дасть результат 0,005. 
Що зробить Math.Round за замовчуванням: округлить до 0,00 чи до 0,01? // Math.Round(0.005, 2) справді дасть 0.00 (бо 0 — парне).

✅ Рішення:
Console.WriteLine("Введіть вашу суму в гривнях (UAH)");
double uah = double.Parse(Console.ReadLine()!);
Console.WriteLine("Введіть код валюти, на яку ви хочете поміняти гроші: 'USD', 'EUR', 'PLN'");
string currency = Console.ReadLine()!;

var result = (currency, uah) switch
{
    ("USD", _) => uah / 40.0,
    ("EUR", < 1000) => uah / 44.0,
    ("EUR", >= 1000) => uah / 43.5,
    ("PLN", _) => uah / 10.0,
    _ => 0
};

Console.WriteLine(Math.Round(result, 2));

📝 Завдання №2: Геометрія та Корінь
Давай спробуємо інший популярний метод — Math.Sqrt (Square Root — квадратний корінь).

Твоя задача:
Користувач вводить число (площу квадрата).
Програма має обчислити довжину сторони цього квадрата.
Використай Math.Sqrt(area).
Виведи результат, округливши його до 3 знаків після коми.
Додатково: Використай Math.Max, щоб порівняти введене число з нулем 
(якщо користувач введе від'ємне число, площа має вважатися рівною 0, щоб програма не видала помилку NaN).

Приклад логіки для захисту:
double safeArea = Math.Max(0, userInput);

✅ Рішення:
Console.WriteLine("Введіть площу квадрата");
double userInput = double.Parse(Console.ReadLine()!);
double safeArea = Math.Max(0, userInput);
double length = Math.Sqrt(safeArea);
Console.WriteLine(Math.Round(length, 3));

📝 Завдання №3: "Логістика та перевезення"
Уяви, що ти розробляєш систему для служби доставки. Тобі потрібно порахувати, скільки цілих машин/коробок знадобиться.

Твоя задача:
Користувач вводить загальну вагу вантажу (наприклад, double totalWeight = 25.4 кг).
Користувач вводить максимальну вагу, яку вміщує одна коробка (наприклад, double capacity = 5.0 кг).
Програма має обчислити:
Скільки повних коробок вийде? (Використай Math.Floor).
Скільки всього коробок потрібно замовити, щоб вліз увесь вантаж? 
(Навіть якщо остання коробка буде заповнена лише на 10% — використай Math.Ceiling).
Виведи обидва результати.
Наприклад: Якщо вага 25.4, а коробка на 5 — повних буде 5, а всього знадобиться 6.

✅ Рішення:
Console.WriteLine("Яка загальна вага вантажу?");
double totalWeidht = double.Parse(Console.ReadLine()!);
Console.WriteLine("А яку вагу вміщує одна коробка?");
double weightInOneBox = double.Parse(Console.ReadLine()!);
Console.WriteLine($"Усього буде заповнено {Math.Floor(totalWeidht / weightInOneBox)} коробок");
Console.WriteLine($"Але знадобиться в сумі {Math.Ceiling(totalWeidht / weightInOneBox)} коробок");

📝 Завдання №4: "Математичний детектив"
Давай закріпимо це практикою. Уяви, що ти розробляєш будівельний калькулятор.

Умова:
Користувач вводить площу круглої ділянки (наприклад, double area = 78.5;).
Тобі потрібно:
Знайти радіус цієї ділянки за формулою: $R = \sqrt{area / \pi}$. (Використай Math.PI для числа Пі та Math.Sqrt).
Знайди мінімальне число між цим радіусом та числом 10.
Округли результат до "стелі" (Math.Ceiling), щоб дізнатися, скільки цілих метрів паркану купити.
Виведи фінальне число в консоль

✅ Рішення:
Console.WriteLine("Введіть площу круглої ділянки");
double area = double.Parse(Console.ReadLine()!);
double radius = Math.Sqrt(area / Math.PI); // Math.Sqrt обчислює корінь числа
double min = Math.Min(radius, 10);
Console.WriteLine($"Радіус - {radius}, а мінімальне число - {min}");
Console.WriteLine($"Потрібно купити {Math.Ceiling(radius)} м паркану");

📐 Фінальне завдання: "Геометричний калькулятор"
Користувач має ввести довжину сторони трикутника a і довжину сторони трикутника b
Твоє завдання:
Гіпотенуза (c): Обчисли її за теоремою Піфагора: $c = \sqrt{a^2 + b^2}$.
Підказка: Використовуй Math.Pow для піднесення до квадрата та Math.Sqrt для кореня.
Площа (S): Обчисли за формулою $S = (a * b) / 2$.
Порівняння: Знайди найменше число (Math.Min) між довжиною гіпотенузи та площею.
Степінь: Піднеси отримане мінімальне число до кубу (степінь 3) і виведи результат.
Твій код має вивести:
1. Довжину гіпотенузи.
2. Площу трикутника.
3. Результат піднесення мінімуму до кубу.

Console.WriteLine("Введіть довжину сторони трикунтика a");
double a = double.Parse(Console.ReadLine()!);
Console.WriteLine("Введіть довжину сторони трикунтика b");
double b = double.Parse(Console.ReadLine()!);

double c = Math.Sqrt(Math.Pow(a, 2) + Math.Pow(b, 2)); // Теорема Піфагора (Math.Sqrt - обічислюєкорінь числа,  а Math.Pow підносить до степеня)
double sArea = (a * b) / 2;
double min = Math.Min(c, sArea);
Console.WriteLine($"Найменше число між довжиною гіпотенузи {c} та площею {sArea} - {min}");
Console.WriteLine($"Якщо піднести це мінімальне число {min} до кубу, то отримаємо {Math.Pow(min, 3)}");
