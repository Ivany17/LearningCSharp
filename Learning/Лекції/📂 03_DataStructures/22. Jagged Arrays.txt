🦷 Тема №22: Зубчасті масиви (Jagged Arrays)
1. 🤔 Що це таке?
Якщо звичайний двовимірний масив [,] — це суворий прямокутник, де всі рядки мають однакову довжину, 
то зубчастий масив — це масив, елементами якого є інші масиви.
Це означає, що кожен рядок може мати свою власну довжину.

2. 🏗️ Як оголосити та створити?
Використовується подвійна пара дужок [][].
int[][] jagged = new int[3][]; — ми кажемо: "Створи масив на 3 рядки, але я поки не знаю, скільки елементів буде в кожному".

Потім кожен рядок треба ініціалізувати окремо:
jagged[0] = new int[2]; (перший рядок — 2 елементи)
jagged[1] = new int[5]; (другий рядок — 5 елементів)

3. 📍 Доступ до елементів
Звернення йде через дві пари дужок: jagged[рядок][стовпець].
jagged[1][4] = 10; — запис у 5-й елемент 2-го рядка.

4. 🔄 Перебір через цикли
Оскільки довжина кожного рядка різна, ми не можемо використовувати одне число. На допомогу приходить властивість .Length:
jagged.Length — кількість рядків.
jagged[i].Length — кількість елементів у конкретному рядку i.

🚂 Якщо уявити і розділити логіку, то вийде, що 
i — номер вагона.
array.Length — це кількість "вагонів" (рядків) у всьому "потязі".
array[i] — сам вагон.
array[i].Length — це кількість "місць" (елементів) всередині конкретного вагона під номером i.
array[i][j] — конкретна людина у вагоні i на місці j.

Якщо твій масив виглядає так:
Рядок 0: [1, 2, 3] (довжина 3)
Рядок 1: [4, 5] (довжина 2)
Рядок 2: [6, 7, 8, 9] (довжина 4)
Тоді:
array.Length буде дорівнювати 3 (бо всього три рядки/вагони).
array[2].Length буде дорівнювати 4 (бо в третьому вагоні 4 пасажири).

📝 Завдання: "Розклад занять"
Уяви, що ти пишеш програму для університету. У студентів різна кількість пар кожного дня:
Понеділок: 2 пари.
Вівторок: 4 пари.
Середа: 3 пари.

Твоє завдання:
Оголоси зубчастий масив рядків string[][] schedule на 3 дні (рядки).
Створи (ініціалізуй) кожен рядок окремо з відповідною кількістю елементів (2, 4, 3).
Заповни їх назвами будь-яких предметів (наприклад, "Математика", "C#", "Фізика").
Використовуючи вкладені цикли for, виведи розклад у консоль.

Підказка для виводу:
Для зовнішнього циклу використовуй i < schedule.Length.
Для внутрішнього — j < schedule[i].Length.

✅ Рішення:
string[][] schedule = new string[3][];
schedule[0] = new string[2];
    schedule[0][0] = "Вища математика";
    schedule[0][1] = "Органічна хімія";
schedule[1] = new string[4];
    schedule[1][0] = "Українська мова професійного спрямування";
    schedule[1][1] = "Фізика";
    schedule[1][2] = "Право";
    schedule[1][3] = "Історія";
schedule[2] = new string[3];
    schedule[2][0] = "Англійська мова";
    schedule[2][1] = "Фізична культура";
    schedule[2][2] = "Біологія";

for(int i = 0; i < schedule.Length; i++)
{
    for(int j = 0; j < schedule[i].Length; j++)
    {
        Console.WriteLine(schedule[i][j]);
    }
}

📝 Завдання:
Давай створимо "зубчасту" таблицю випадкових чисел.
Створи масив на 3 рядки: int[][] numbers = new int[3][];
Ініціалізуй їх різною довжиною:
1-й рядок — 2 елементи.
2-й рядок — 5 елементів.
3-й рядок — 3 елементи.
Напиши вкладений цикл, щоб заповнити кожен елемент випадковим числом (наприклад, 1–10).
Виведи результат у консоль так, щоб кожен масив був у своєму рядку.

✅ Рішення:
Random generator = new Random();
int[][] numbers = new int[3][];
numbers[0] = new int[2];
numbers[1] = new int[5];
numbers[2] = new int[3];

for(int i = 0; i < numbers.Length; i++)
{
    for(int j = 0; j < numbers[i].Length; j++)
    {
        Console.Write($"{numbers[i][j] = generator.Next(1, 11)} ");
    }
    Console.WriteLine();
}

📝 Завдання:
Створи зубчастий масив на 4 рядки. Довжину кожного рядка вибери сам (але нехай вони будуть різними).
Заповни його випадковими числами від 1 до 100.
Виведи масив, а під ним виведи:
Суму чисел у найдовшому рядку (тобі доведеться візуально або кодом визначити, який рядок найдовший, і порахувати його).
Середнє значення всього масиву (тут уважно: загальна сума всіх чисел ділиться на загальну кількість елементів).
Підказка для середнього значення: Тобі знадобиться змінна totalSum і змінна totalCount. Кожного разу, коли додаєш число, роби totalCount++.

✅ Рішення:
Random generator = new Random();
int[][] array = new int[4][];
array[0] = new int [3];
array[1] = new int [2];
array[2] = new int [4];
array[3] = new int [3];

for(int i = 0; i < array.Length; i++)
{
    for(int j = 0; j < array[i].Length; j++)
    {
        Console.Write($"{array[i][j] = generator.Next(1, 101)} ");
    }
    Console.WriteLine();
}
int bigestIndex = 0; // шукаємо рядок з найбільшим індексом [i], бо він найдовший
for(int i = 0; i < array.Length; i++)
{
    if(array[i].Length > array[bigestIndex].Length)
    {
        bigestIndex = i;
    }
}
int sum = 0; // підсумовуємо усі числа в найдовшому рядку
for(int j = 0; j < array[bigestIndex].Length; j++)
{
    sum += array[bigestIndex][j];
}
Console.WriteLine($"Сума чисел в найдовшому рядку: {sum}");
int totalSum = 0; // для підрахунку чисел у всьому масиві
int totalCount = 0; // для підразунку кількості елементів в масиві
for(int i = 0; i < array.Length; i++)
{
    for(int j = 0; j < array[i].Length; j++)
    {
        totalSum += array[i][j];
        totalCount++;
    }
}
Console.WriteLine($"В масиві всього {totalCount} чисел і їх сума: {totalSum}");
Console.WriteLine($"Середнє значення всього масиву {(double)totalSum / totalCount}");

📝 Завдання:
Уяви, що ти керуєш логістичним центром. У тебе є 3 вантажівки (рядки масиву), і кожна з них перевозить різну кількість посилок (елементи масиву).
Твоє завдання:
Створи зубчастий масив int[][] trucks = new int[3][];.
Ініціалізуй вантажівки так:
Перша — 3 посилки.
Друга — 6 посилок.
Третя — 4 посилки.
Заповни їх випадковими числами від 10 до 50 (це буде вага кожної посилки в кг).
Виведи всі вантажівки на екран (кожна вантажівка — новий рядок).
Головна частина: Знайди і виведи в консоль:
Загальну вагу другої вантажівки (індекс 1).
Індекс вантажівки, у якій найлегша перша посилка (порівняй trucks[i][0] у всіх трьох).

✅ Рішення:
Random generator  = new Random();
int[][] trucks = new int[3][];
trucks[0] = new int[3];
trucks[1] = new int[6];
trucks[2] = new int[4];

for(int i = 0; i < trucks.Length; i++)
{
    for(int j = 0; j < trucks[i].Length; j++)
    {
        trucks[i][j] = generator.Next(10, 51);
        Console.Write(trucks[i][j] + "\t");
    }
    Console.WriteLine();
}
int sumWeight = 0; // для пошуку загальної ваги в другій вантажівці під індексом [1]
for(int i = 0; i < trucks[1].Length; i++)
{
    sumWeight += trucks[1][i];
}
Console.WriteLine($"Загальна вага посилок в другій вантажівці: {sumWeight} кг");
int lightPackage = 0; // для пошуку найлегшої посилки
for(int i = 0; i < trucks.Length; i++)
{
    for(int j = 0; j < trucks[i].Length; j++)
    {
        if(trucks[i][0] < trucks[lightPackage][0])
        {
            lightPackage = i;
        }
    }
}
Console.WriteLine($"В вантажівці під індексом [{lightPackage}] найлегша перша посилка, яка має вагу {trucks[lightPackage][0]} кг");
