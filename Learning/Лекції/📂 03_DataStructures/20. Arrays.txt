Тема №20: Масиви (Arrays) 🗃️
Досі ми створювали окрему «коробку» (змінну) для кожного значення. 
Але що, як нам потрібно зберегти список із 100 назв міст або 50 оцінок? Створювати 50 змінних вручну — не варіант.

Для цього існують масиви — це одна змінна, яка може містити в собі цілий список значень однакового типу.

⚠️ Як це працює:
Ми вказуємо тип даних і ставимо квадратні дужки [].
Перелічуємо значення у фігурних дужках {}.

🔑 Приклад:
string[] fruits = { "Яблуко", "Банан", "Апельсин" };

‼️ Важливо: як дістати значення:
У програмуванні рахунок завжди починається з нуля.
fruits[0] — це "Яблуко".
fruits[1] — це "Банан".
fruits[2] — це "Апельсин".

// Якщо хочеш, наприклад, додати в масив на 5 значень числа від одного до п'яти
int[] nums = new int[5];
for(int i = 0; i < nums.Length; i++)
{
    Console.WriteLine(nums[i] = i + 1);
}

📝 Завдання:
Створи масив на 5 випадкових чисел (використовуй Random).
Виведи їх.
Знайди суму всіх цих чисел і виведи її в кінці.
Тобі знадобиться створити змінну int sum = 0; перед циклом і додавати до неї кожне число з масиву.

✅ Рішення:

{
    Console.WriteLine(nums[i] = generator.Next(1,101));

    sum += nums[i];
}

🏋️‍♂️ Практичний іспит: «Аналітик температур»
Уяви, що ти пишеш програму для метеостанції. Твоє завдання:
Створити масив цілих чисел на 7 елементів (це буде тиждень).
Заповнити його випадковими числами (температурою) в діапазоні від -10 до +10 градусів.
Вивести всі температури в один рядок, щоб бачити картину тижня.
Аналіз (найважливіше):
Порахуй та виведи середню температуру за тиждень (сума всіх чисел, поділена на 7).
Порахуй та виведи, скільки днів було «морозних» (температура менше 0).

✅ Рішення:
Random temperature = new Random();
int[] day = new int[7];
for(int i = 0; i < day.Length; i++)
{
    Console.Write($"День {i + 1} температура {day[i] = temperature.Next(-10, 11)} | ");
}
int sum = 0;
for(int i = 0; i < day.Length; i++)
{
    sum += day[i];
}
double average = (double)sum / day.Length;
Console.WriteLine();
Console.WriteLine($"Середня температура {average:F2}");
int amount = 0;
for(int i = 0; i < day.Length; i++)
{
    if(day[i] < 0)
    {
        amount++;
    }
}
Console.WriteLine($"Кількість морозних днів - {amount}");
