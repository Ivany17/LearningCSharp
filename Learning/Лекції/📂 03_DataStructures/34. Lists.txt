Тема №34: Списки (Lists) 📜
Масиви, які ми вивчали раніше, мають один мінус: їхній розмір не можна змінити після створення. 
Якщо ти створив масив на 4 гри, то 5-ту туди вже не запхаєш.
🧬 Типізація: Буква <T> (Generic) означає, що ти сам кажеш, об'єкти якого типу будуть у списку (наприклад, List<int> або List<SmartDevice>).

У реальних програмах частіше використовують List (Список). ‼️ Він автоматично розширюється, коли ти додаєш нові елементи.

⚠️ Як це працює:
📚 Треба додати зверху: using System.Collections.Generic; (зазвичай VS Code робить це сам).

▶️ Створюємо список:
List<string> inventory = new List<string>();

➕ Додаємо елементи:
inventory.Add("Меч"); — додати в кінець.
inventory.Add("Щит");

➖ Видаляємо:
inventory.Remove("Меч");

Кількість	int count = names.Count; (не Length!)
Доступ	string first = names[0]; (як у масивах)

names.Insert(0, "текст") — вставити в конкретне місце.
names.Contains("текст") — чи є таке в списку?
names.IndexOf("текст") — який номер у цього елемента?
names.Remove("текст") — видалити саме це слово.
names.RemoveAt(0) — видалити за номером.
names.Sort() — сортувати (для рядків — за алфавітом, для чисел — від меншого до більшого).
names.Count — скільки всього елементів.

📝 Завдання №34:
Давай створимо динамічний інвентар для твого гравця.
Створи список рядків List<string> items.
Додай у нього три будь-які предмети (наприклад, "Аптечка", "Зброя", "Карта").
Виведи в консоль кількість предметів у списку, використовуючи властивість Count:
"В інвентарі зараз: {items.Count} предметів".
Видали один предмет за допомогою Remove().
Знову виведи кількість предметів, щоб переконатися, що список зменшився.

✅ Рішення:
using System.Collections.Generic;

List<string> items = new List<string>();
items.Add("Аптечка");
items.Add("Зброя");
items.Add("Карта");

Console.WriteLine($"В інвентарі зараз: {items.Count} предметів"); // в консолі "В інвентарі зараз: 3 предметів"

items.Remove("Зброя");

Console.WriteLine($"В інвентарі зараз: {items.Count} предметів"); // в консолі "В інвентарі зараз: 2 предметів"

📝 Завдання: "Менеджер імен"
Тобі потрібно створити програму, яка маніпулює списком імен. Це дозволить перевірити всі основні методи List<string>.
Виконай наступні кроки:
Створення: Створи порожній список List<string> names.
Наповнення: Додай у список 3 імені: "Ivan", "Olena", "Alex".
Вставка: Використай метод .Insert(), щоб додати ім'я "Max" на перше місце (індекс 0).
Перевірка: Використай метод .Contains(), щоб дізнатися, чи є в списку ім'я "Ivan". Результат (true/false) виведи в консоль.
Пошук індексу: Використай метод .IndexOf(), щоб дізнатися, під яким номером у списку стоїть "Alex". Виведи цей номер.
Видалення за іменем: Видали зі списку "Olena".
Видалення за номером: Видали перший елемент списку (той, що під індексом 0).
Сортування: Виклич метод .Sort(), щоб відсортувати імена за алфавітом.
Фінал: Виведи через foreach всі імена, що залишилися, а в кінці — загальну кількість елементів через .Count.

✅ Рішення:
List<string> names = new List<string>();
names.Add("Ivan");
names.Add("Olena");
names.Add("Alex");
names.Insert(0, "Max"); // вставити Max на перше місце (індкс 0)
Console.WriteLine($"Чи є в списку ім'я {names[1]} - {names.Contains("Ivan")}");
Console.WriteLine($"{names[3]} знаходиться в списку під індексом {names.IndexOf("Alex")}");
names.Remove("Olena");
names.RemoveAt(0);
names.Sort();
foreach(var name in names)
{
    Console.WriteLine(name);
}
