Тема №23: Цикл Foreach (Перебір масивів) 🔄📦
Ми вже знаємо, як діставати елементи з масиву по одному через [індекс]. Але якщо в масиві 100 ігор, 
виводити їх вручну — занадто довго. Для роботи з масивами існує спеціальний, дуже зручний цикл — foreach (для кожного).
Він сам проходить по всьому списку від початку до кінця, підставляючи кожен елемент у тимчасову змінну.

🔑 Приклад:

string[] names = { "Іван", "Марія", "Олег" };

foreach (string name in names) 
{
    Console.WriteLine($"Привіт, {name}!");
}

string name — це тимчасова "коробка", куди цикл по черзі кладе кожне ім'я з масиву.
in names — вказує, з якого саме масиву брати дані.

📝 Завдання №23:
Давай виведемо весь твій список ігор одним махом.
Використай свій масив games із попереднього завдання.
Напиши цикл foreach, який пройдеться по всьому масиву.
Всередині циклу виведи назву кожної гри у форматі: "Я люблю грати в {game}".

✅ Рішення:
string[] games = { "GTA V", "NFS Rivals", "The Crew", "Counter-Strike"};
foreach(string favoriteGame in games)
{
    Console.WriteLine($"Я люблю грати в {favoriteGame}");
}

📝 Завдання "Фільтратор" (Закріплення foreach)
Давай зробимо завдання, де foreach проявить себе найкраще — у швидкому переборі та перевірці умов.
Створи масив int[] inventory = { 5, 12, 3, 25, 8, 30, 2, 15 };.
Уяви, що це кількість товарів на складі. Тобі потрібно знайти "критичні залишки" (менше 10 одиниць).
Використовуй foreach, щоб пройтися по масиву.
Всередині циклу: якщо число менше 10, виведи повідомлення: "Увага! Мало товару: [число]".
Додатково: після циклу виведи, скільки всього позицій потребують поповнення (використовуй лічильник).

✅ Рішення:
int[] inventory = { 5, 12, 3, 25, 8, 30, 2, 15 };
int count = 0;
foreach(int less in inventory)
{
    if(less < 10)
    {
        Console.WriteLine($"Увага! Мало товару: {less}");
        count++;
    }
}
Console.WriteLine($"Кількість товарів, що потребують поповнення: {count}");

📝 Завдання "Аналітик складів"
Давай поєднаємо зубчасті масиви і foreach
Створи зубчастий масив int[][] warehouse = new int[3][];.
Ініціалізуй його:
1-й рядок: 2 елементи
2-й рядок: 4 елементи
3-й рядок: 3 елементи
Заповни його будь-якими числами (можна вручну або через for, як тобі зручніше).
Використовуючи вкладений foreach:
Виведи весь масив на екран.
Порахуй загальну суму всіх чисел у всьому зубчастому масиві.
Виведи фінальну суму після всіх циклів.

✅ Рішення:
Random generator = new Random();
int[][] warehouse = new int[3][];
warehouse[0] = new int[2];
warehouse[1] = new int[4];
warehouse[2] = new int[3];

for(int i = 0; i < warehouse.Length; i++)
{
    for(int j = 0; j < warehouse[i].Length; j++)
    {
        warehouse[i][j] = generator.Next(1, 51);
    }
}
int sum = 0 ;
foreach(int[] row in warehouse)
{
    foreach(int item in row)
    {
        Console.Write(item + " ");
        sum += item;
    }
    Console.WriteLine();   
}
Console.WriteLine($"Сума всіх чисел {sum}");

📝 Завдання: "Звіт по відділах"
Уяви, що int[][] sales — це продажі в магазині за 3 дні. Кожен рядок — це окремий день, а елементи в ньому — суми чеків різних покупців.
Умови:
Створи масив на 3 дні (рядки). Кількість чеків (елементів) у кожному дні нехай буде різною (наприклад: 3, 5, 2).
Заповни їх випадковими числами від 50 до 1000 (суми покупок).
Використовуй вкладений foreach, щоб:
Вивести всі чеки по днях.
Порахувати загальний виторг за всі 3 дні.
Головна фішка: Порахувати, скільки всього було "великих" чеків (сума яких більша за 100).

✅ Рішення:
Random generator = new Random();
int[][] sales = new int[3][];
sales[0] = new int[3];
sales[1] = new int[5];
sales[2] = new int[2];
int sum = 0;
int count = 0;
for(int i = 0; i < sales.Length; i++)
{
    for(int j = 0; j < sales[i].Length; j++)
    {
        sales[i][j] = generator.Next(1, 51);
    }
}

foreach(int[] row in sales)
{
    int priceInOneCheck = 0; // обнуляємо один чек кожен день
    foreach(int price in row)
    {
        Console.Write(price + "\t");
        sum += price;
        priceInOneCheck += price; // в чек додаємо ціну усіх товарів, які є в ньому
    }
        if(priceInOneCheck > 100)
        {
            count++;
        }
    Console.WriteLine();
}
Console.WriteLine($"Загальний виторг за 3 дні: {sum} грн");
Console.WriteLine($"У нас усього {count} чеки, сума яких перевищує 100 грн");
