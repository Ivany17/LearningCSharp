🗺️ Тема №21: Двовимірні масиви (2D Arrays)
1. 📋 Що це таке?
Двовимірний масив — це масив масивів. Він складається з рядків та стовпців. Кожен елемент тепер має не один індекс, а два: [рядок, стовпець].

2. 🏗️ Як оголосити та створити?
У C# для цього використовується кома всередині квадратних дужок [,].
int[,] table = new int[3, 4]; — створює порожню таблицю на 3 рядки та 4 стовпці.
int[,] map = { {1, 2}, {3, 4}, {5, 6} }; — створення з одразу заданими значеннями.

3. 📍 Як отримати доступ до елемента?
Завжди вказуємо спочатку номер рядка, потім стовпця (індексація починається з 0).
table[0, 0] = 10; — верхній лівий кут.
int val = table[2, 3]; — елемент у 3-му рядку та 4-му стовпці.

4. 🔄 Як обійти весь масив?
Для цього нам знадобляться вкладені цикли for. Зовнішній цикл іде по рядках, а внутрішній — по стовпцях.
GetUpperBound(0) — повертає індекс останнього рядка.
GetUpperBound(1) — повертає індекс останнього стовпця.

У всіх циклах for аби знайти довжину ми використовуємо GetLength:
Для зовнішнього циклу (i): i < array.GetLength(0)
Для внутрішнього циклу (j): j < array.GetLength(1)

📝 Завдання #21: "Магічна таблиця 3х3"
Давай створимо просту таблицю, заповнимо її числами та виведемо у гарному вигляді.
Умова:
Створи двовимірний масив int[,] matrix = new int[3, 3];.
Заповни його будь-якими числами вручну або через цикл.
За допомогою вкладених циклів for виведи масив у консоль так, щоб він виглядав як таблиця (використовуй Console.Write для елементів рядка та 
Console.WriteLine() після завершення кожного рядка).

✅ Рішення:
int[,] matrix = new int[3, 3];
int count = 1;
for(int i = 0; i < matrix.GetLength(0); i++)
{
    for(int j = 0; j < matrix.GetLength(1); j++)
    {
        matrix[i, j] = count;
        count++;
    }
}
for(int i = 0; i < matrix.GetLength(0); i++)
{
    for(int j = 0; j < matrix.GetLength(1); j++)
    {
        Console.Write(matrix[i, j] + " ");
    }
    Console.WriteLine();
}

📝 Завдання: Створи таблицю множення 3х3 (але не на індекси, а на реальні числа).

Умова:
Заповни масив так, щоб у кожній клітинці був результат множення: (i + 1) * (j + 1).
(Ми додаємо 1, щоб не множити на нуль і отримати таблицю від 1 до 3).
Виведи її в консоль.
Бонус: Замість matrix[i, j] + " " спробуй використати matrix[i, j] + "\t".
(\t — це табуляція, вона робить колонки ідеально рівними, як у таблиці).

✅ Рішення:
int[,] matrix = new int[3, 3];
for(int i = 0; i < matrix.GetLength(0); i++)
{
    for(int j = 0; j < matrix.GetLength(1); j++)
    {
        matrix[i, j] = (i + 1) * (j + 1);
    }
}
for(int i = 0; i < matrix.GetLength(0); i++)
{
    for(int j = 0; j < matrix.GetLength(1); j++)
    {
        Console.Write(matrix[i, j] + "\t");
    }
    Console.WriteLine();
}

📝 Завдання: Створи масив int[,] table = new int[3, 4]; (3 рядки, 4 стовпчики).
Додай ще один вкладений цикл перед виводом, щоб заповнити весь масив випадковими числами від 1 до 100.
Додай логіку, яка знайде і виведе:
Найбільше число у всій таблиці.
Суму чисел тільки першого рядка (індекс 0).
Суму чисел лише останнього стовпчика (table.GetLength(1) - 1)

✅ Рішення:
Random generator = new Random();
int[,] table = new int[3, 3];
for (int i = 0; i < table.GetLength(0); i++)
{
    for (int j = 0; j < table.GetLength(1); j++)
    {
        table[i, j] = generator.Next(1, 101); // заповнюємо масив рандомними числами від 1 до 100
    }
}
int max = table[0, 0]; // для пошуку найбільшого числа у всій таблиці
for (int i = 0; i < table.GetLength(0); i++)
{
    for (int j = 0; j < table.GetLength(1); j++)
    {
        Console.Write(table[i, j] + "\t"); // відображаємо числа в масиві
        if(table[i, j] > max)
        {
            max = table[i, j]; // шукаємо максимальне число в таблиці
        }
    }
    Console.WriteLine();
}
Console.WriteLine($"Максимальне число в таблиці: {max}");
int sum = 0; // для підрахунку чисел у першому рядку
for(int j = 0; j < table.GetLength(1); j++) //  table.GetLength(1) - бо ми рахуємо саме стовпчики
{
    sum += table[0, j];
}
Console.WriteLine($"Сума чисел у першому рядку: {sum}");
int sumLast = 0; // для підрахунку чисел в останньому стовпчику
for(int i = 0; i < table.GetLength(0); i++) //  table.GetLength(0) - бо ми рахуємо саме рядки
{
    sumLast += table[i, table.GetLength(1) - 1]; // table.GetLength(1) - 1 дає останній стовпчик
}
Console.WriteLine($"Сума чисел в останньому стовпчику: {sumLast}");
