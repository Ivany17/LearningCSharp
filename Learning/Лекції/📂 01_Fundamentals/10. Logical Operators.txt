Тема №10: Складні умови (Logical Operators) 🧩
Бувають випадки, коли однієї умови замало. Наприклад: "Тобі дозволено вхід, якщо тобі є 18 І у тебе є квиток". 
Або: "Ти отримаєш знижку, якщо ти студент АБО пенсіонер".

📌 В C# для цього є два головні знаки:

&& — це "І" (AND). Умова буде правдивою, тільки якщо ОБИДВІ частини правильні.
|| — це "АБО" (OR). Умова буде правдивою, якщо ХОЧА Б ОДНА частина правильна.

🔑 Приклад:
int age = 20;
bool hasTicket = true;

if (age >= 18 && hasTicket == true) 
{
    Console.WriteLine("Проходьте!");
}

📝 Завдання №10:
Давай перевіримо, чи може людина купити енергетик.
Умови: енергетик продають, якщо людині є 18 років, АБО якщо з нею є батьки.
Запитай вік і конвертуй його в int userAge.
Запитай: "Чи з тобою є батьки? (true/false)". Зчитай це у string input.
Конвертуй ввід про батьків у bool withParents за допомогою Convert.ToBoolean(input). 
(Тут користувачу треба буде буквально написати слово true або false).
Напиши if, який перевіряє: (userAge >= 18 || withParents == true).
Якщо хоча б одна умова підходить — виведи: "Продаж дозволено!".
Інакше — виведи: "Продаж заборонено!".

✅ Рішення:
Console.WriteLine("Скільки тобі років?");
string inputAge = Console.ReadLine() ?? "";
int userAge = Convert.ToInt32(inputAge);

Console.WriteLine("Чи з тобою є батьки?");
string boolParents = Console.ReadLine() ?? "";
bool withParents = Convert.ToBoolean(boolParents);

if(userAge >= 18 || withParents == true)
{
    Console.WriteLine("Продаж дозволено!");
} else
{
    Console.WriteLine("Продаж заборонено!");
}
