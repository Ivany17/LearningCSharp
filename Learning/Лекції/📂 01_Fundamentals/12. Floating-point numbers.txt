Тема №12: Робота з дробовими числами (Floating-point numbers) 🥧
Досі ми працювали тільки з цілими числами (int), як-от 5 або 100. Але в житті часто бувають ситуації, 
де потрібна точність: ціна 10.50, вага 0.7 або число π.

Для таких випадків у C# найчастіше використовують тип double.

🆎 Особливості:
Дробова частина у файлі відділяється крапкою (.), а не комою.
В ТЕРМІНАЛІ ДРОБОВА ЧАСТИНА ВІДДІЛЯЄТЬСЯ КОМОЮ (,), А НЕ КРАПКОЮ.
При діленні double на число, ми отримуємо точний результат з хвостиком.

🔀 Порівняння:
int a = 5 / 2; — вийде 2.
double b = 5.0 / 2.0; — вийде 2.5.

Щоб перетворити ввід користувача на дробове число, ми використовуємо Convert.ToDouble().

Давай створимо калькулятор середнього бала.
Запитай у користувача оцінку за перший іспит (наприклад, 4.5) і збережи її в double grade1.
Запитай оцінку за другий іспит і збережи в double grade2.
Створи третю змінну double average, яка дорівнює їхній сумі, поділеній на 2.
Підказка: використовуй дужки, щоб спершу додати, а потім ділити: (g1 + g2) / 2.
Виведи результат: "Твій середній бал: {average}".

✅ Рішення:
Console.WriteLine("Яка твоя оцінка за перший іспит?");
string inputFirstExam = Console.ReadLine() ?? "";
double grade1 = Convert.ToDouble(inputFirstExam);

Console.WriteLine("Яка твоя оцінка за другий іспит?");
string inputSecondExam = Console.ReadLine() ?? "";
double grade2 = Convert.ToDouble(inputSecondExam);

Console.WriteLine($"Твій середній бал: {average}");

Умови (без підказок щодо структури):

один через double, інший через decimal).
Обчисли загальну суму для обох типів.

Виведи обидва результати в консоль.
Порада: Використовуй інтерполяцію рядків. Щоб побачити багато знаків після коми, можеш написати так: {sum:F20} (це виведе 20 знаків).
Напиши логічну перевірку (if): чи рівні ці дві суми між собою? Виведи результат порівняння.
Спробуй ввести такі дані, щоб double «помилився» (наприклад, ціна 0.1, кількість 10).

✅ Рішення:
Console.WriteLine("Яка ціна товару?");
string price = Console.ReadLine()!; // 0,6
decimal pricedec = decimal.Parse(price);
double pricedou = double.Parse(price);
Console.WriteLine("Яка кількість одиниць товару?");
string amount = Console.ReadLine()!; // 12
decimal amountdec = decimal.Parse(amount);
double amountdou = double.Parse(amount);

decimal sumdec = pricedec * amountdec;
double sumdou = pricedou * amountdou;

decimal taxdec = sumdec + 0.0000000000001m; // m - чітко вкзаує на decimal, який і використовується в банківських операціях
double taxdou = sumdou + 0.0000000000001;

Console.WriteLine($"Decimal sum: {taxdec:F20}"); // Decimal sum: 7,20000000000010000000 (:F20 залишає 20 символів після коми)
Console.WriteLine($"Double sum: {taxdou:F20}"); // Double sum: 7,20000000000009965362

// Оскільки програма не може правильно порівняти decimal і double - прийшлося порівнювати ці числа, перетворивши їх на string
if (taxdec.ToString("F20") == taxdou.ToString("F20"))
{
    Console.WriteLine("Ці числа рівні");
} else
{
    Console.WriteLine("Ці числа не рівні"); // Ці числа не рівні
}



📝 Завдання: "Цифровий пил"
Уяви, що ти розробляєш систему для банку, яка нараховує дуже маленьку комісію (наприклад, за користування сервісом) мільйон разів поспіль.

Твоя задача:
Створи три змінні: float fSum = 0f;, double dSum = 0;, decimal mSum = 0m;.
Користувач має ввести кількість повторень (наприклад, 10 000) та суму комісії (наприклад, 0.0001).
Використай цикл for.
Виведи фінальні результати всіх трьох сум з точністю :F20.
Також виведи "ідеальну" суму, яку можна отримати простою арифметикою: комісія * кількість.
Факти для реалізації (без підказок щодо порядку):
Якщо кількість повторень менша або дорівнює 0 — виведи повідомлення про помилку.
Програма має показати, наскільки сильно float та double "відхилилися" від точного decimal.

✅ Рішення:
float fSum = 0f; // f - чітко вказує на float
double dSum = 0;
decimal mSum = 0m; // m - чітко вказує на decimal

Console.WriteLine("Введіть кількість повторень операції");
int repeat = int.Parse(Console.ReadLine()!); // 10000

Console.WriteLine("Введіть суму комісії");
string comission = Console.ReadLine()!; // 0,00001
float fcomission = float.Parse(comission);
double dcomission = double.Parse(comission);
decimal mcomission = decimal.Parse(comission);

if(repeat > 0)
{
    for(int i = 0; i < repeat; i++)
    {
        fSum += fcomission;
        dSum += dcomission;
        mSum += mcomission;
    }
} else
{
    Console.WriteLine("Помилка! Кількість повторень має бути більше нуля");
}

decimal idealSum = mcomission * repeat;

Console.WriteLine($"float: {fSum:F20}"); // float: 0,09999150037765502930 (:F20) - залишає 20 знаків після коми
Console.WriteLine($"double: {dSum:F20}"); // double: 0,09999999999999392708
Console.WriteLine($"decimal: {mSum:F20}"); // decimal: 0,10000000000000000000
Console.WriteLine($"idealSum: {idealSum:F20}"); // idealSum: 0,10000000000000000000
