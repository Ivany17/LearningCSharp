Тема №11: Коментарі в коді (Comments in Code) 📝
Іноді коду стає так багато, що навіть через день можна забути, навіщо ти написав той чи інший рядок. Для цього програмісти використовують коментарі — це текст, який комп'ютер просто ігнорує. Він написаний лише для людей.

📌 В C# є два види коментарів:
Однорядковий: починається з двох похилих ліній //. Все, що після них у цьому рядку, комп'ютер не читає.

// Це я рахую податки
int tax = 100;

Багаторядковий: починається з /* і закінчується */. Зручно для великих пояснень.

/* Це великий коментар
на кілька рядків */

📝 Завдання №11:
Давай наведемо лад у твоєму останньому коді про енергетики.
Візьми свій код із завдання №10.
Додай до нього коментарі:
Перед початком програми напиши однорядковий коментар: // Програма для перевірки продажу напоїв.
Перед блоком if напиши багаторядковий коментар, де коротко поясни правила: "Продаємо, якщо людина доросла або якщо поруч батьки".
В кінці якогось рядка з Console.WriteLine допиши маленький коментар: // Вивід результату.
Запусти програму, щоб переконатися, що коментарі ніяк не заважають їй працювати.

✅ Рішення:
// Програма для перевірки продажу напоїв
Console.WriteLine("Скільки тобі років?");
string inputAge = Console.ReadLine() ?? "";
int userAge = Convert.ToInt32(inputAge);

/* Продаємо, якщо людина доросла або якщо поруч батьки */
Console.WriteLine("Чи з тобою є батьки?");
string boolParents = Console.ReadLine() ?? "";
bool withParents = Convert.ToBoolean(boolParents);

if(userAge >= 18 || withParents == true)
{
    Console.WriteLine("Продаж дозволено!");
} else
{
    Console.WriteLine("Продаж заборонено!");
    // Вивід результату
}
