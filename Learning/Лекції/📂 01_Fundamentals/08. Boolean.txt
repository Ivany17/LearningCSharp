Тема №8: Логічні вирази та порівняння (Boolean Logic and Comparison) ⚖️
Тепер ми навчимо програму не просто рахувати, а й порівнювати речі між собою. Результатом порівняння завжди буде одна з двох відповідей: True (Правда) або False (Брехня).

📌 В C# для цього є спеціальні знаки:
> — більше
< — менше
>= — більше або дорівнює
== — дорівнює (Важливо: два знаки "=", бо один знак — це "покласти значення в коробку", а два — це "перевірити, чи вони однакові")
!= — не дорівнює

Ці результати зберігаються в типі даних, який називається bool.

🔑 Приклад:
int myMoney = 100;
int price = 150;

bool canBuy = myMoney >= price; 
Console.WriteLine($"Чи можу я це купити? {canBuy}"); // Напише False

📝 Завдання №8:
Давай перевіримо, чи може користувач отримати водійське посвідчення.
Запитай у користувача його вік і конвертуй у int.
Створи змінну типу bool з назвою isAdult.
Присвой їй результат порівняння: чи вік більше або дорівнює 18.
Виведи в термінал фразу: "Тобі вже є 18 років? {isAdult}".

✅ Рішення:
Console.WriteLine("Скільки тобі років?");
string inputAge = Console.ReadLine() ?? "";
int userAge = Convert.ToInt32(inputAge);

bool isAdult = userAge >= 18;
Console.WriteLine($"Тобі вже є 18 років? {isAdult}");
