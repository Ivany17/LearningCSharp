Тема №5: Введення даних або Як «чути» користувача (User Input) 👂
До цього моменту наша програма була «монологом»: ми самі записували дані в змінні. Але справжня програма має вміти спілкуватися з користувачем.

Щоб комп'ютер зупинився і зачекав, поки ти щось надрукуєш на клавіатурі, використовується команда:
Console.ReadLine();

⚠️ Як це працює:
Команда ReadLine() зчитує те, що ти написав, і повертає це як текст (string).
Ми маємо одразу "впіймати" цей текст у змінну.

🔑 Приклад:
Console.WriteLine("Як тебе звати?");
string name = Console.ReadLine(); // Програма чекає на твій ввід
Console.WriteLine($"Привіт, {name}!");

☢️ Nullable Warnings - C# переживає, що функція Console.ReadLine() може повернути null (пустоту), 
якщо, наприклад, потік введення буде раптово перервано. Оскільки твої змінні userCity, userYear тощо оголошені 
як звичайні string, вони "не мають права" бути пустими.

Ось три способи, як цього позбутися в порядку від найшвидшого до найбільш правильного:

1️⃣ Спосіб 1: Використання Null-умовного оператора ?
Найпростіший варіант — сказати C#, що ці змінні можуть бути порожніми. Для цього до типу string додається знак питання.

Було: string userCity = Console.ReadLine();
Стало: string? userCity = Console.ReadLine();

2️⃣ Спосіб 2: Оператор "помилуй-і-прости" ! (null-forgiving)
Якщо ти на 100% впевнений, що ReadLine не поверне null (у звичайній консолі так і є), ти можеш поставити знак оклику в кінці методу. 
Це буквально каже компілятору: "Замовкни, я знаю, що роблю!".

Застосування: string userCity = Console.ReadLine()!;

3️⃣ Спосіб 3: Значення за замовчуванням ??
Це найбільш безпечний варіант. Якщо ReadLine раптом поверне null, ми підставимо свій текст (наприклад, порожній рядок).

Застосування: string userCity = Console.ReadLine() ?? "";

📝 Завдання №5:
Давай зробимо програму-анкету.

Спершу програма має запитати: "В якому місті ти живеш?".
Ти маєш створити змінну string userCity і записати туди відповідь за допомогою Console.ReadLine().
Потім програма має запитати: "Який зараз рік?".
Створи змінну string userYear (поки що використаємо string для простоти) і теж запиши туди ввід через Console.ReadLine().
Наприкінці виведи фінальну фразу за допомогою інтерполяції ($):
"Ого, ти з міста {userCity} і зараз {userYear} рік!"

Порада: Після запуску програми (dotnet run) не забудь клікнути мишкою в термінал і натиснути Enter після того, як введеш текст. ⌨️

✅ Рішення:
Console.WriteLine("В якому місті ти живеш?");
string userCity = Console.ReadLine() ?? ""; // додаємо ( ?? "" ) - для того, щоб не з'являлися жовті помилки
Console.WriteLine("Який зараз рік?");
string userYear = Console.ReadLine() ?? "";
Console.WriteLine($"Ого, ти з міста {userCity} і зараз {userYear} рік!");
