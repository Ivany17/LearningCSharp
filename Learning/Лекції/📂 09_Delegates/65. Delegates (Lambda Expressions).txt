Тема №65: Лямбда-вирази — Магія стислого коду ✨
До цього моменту ми працювали з делегатами так: спочатку створювали окремий іменований метод (наприклад, InvertSignal), 
а потім передавали його назву в інший метод. Це надійно, але іноді занадто розлого. ✍️
Лямбда-вираз — це "швидкий" спосіб написати логіку методу прямо там, де він потрібен, не вигадуючи йому імені.

📜 Як це працює?
Уяви, що делегат — це замовлення на роботу.
Раніше: Ти дзвонив фахівцю за іменем (назва методу).
Зараз: Ти просто кажеш: "Зроби ось так", описуючи дію прямо в інструкції. 📝
Синтаксис лямбда-виразу виглядає так: (параметри) => дія.
Символ => програмісти називають "йде до" або "lambda arrow".

💡 Приклади перетворення
Давай подивимося, як змінюється код. Наприклад, для твого делегата SignalProcessor:
Було (іменований метод):
bool InvertSignal(bool signal) 
{ 
    return !signal; 
}
// Виклик:
ProcessSensor("Світло", true, InvertSignal);

Стало (лямбда-вираз):
ProcessSensor("Світло", true, s => !s);
Тут s — це вхідний параметр (твій bool signal), а !s — те, що метод повертає. C# сам розуміє типи даних, тому нам не треба писати bool. 🧠

🧩 Що має бути в коді обов'язково:
Делегат — це наш "контракт". Він нікуди не зникає.
Метод-виконавець — це наша "машина", яка вміє приймати числа та виконувати з ними якусь дію. Він теж залишається.
Лямбда — це лише спосіб "на льоту" написати дію для методу-виконавця.

Лямбда-вирази можуть бути не лише в один рядок. Якщо тобі потрібна складна логіка (наприклад, з if або декількома діями), 
ти можеш використовувати тіло запиту з фігурними дужками { }.
Порівняй:
Одиночна лямбда: (x, y) => x + y (автоматично повертає результат).

Блочна лямбда:
(x, y) => {
int sum = x + y;
return sum; // Тут 'return' обов'язковий!
}

🛠️ Завдання №65.1: Анонімний Математик
Створи делегат MathOperation (який приймає два int і повертає int).
Раніше для додавання і множення ми б створили методи Add чи Multiply, але не сьогодні.
Твоє завдання:
Створи метод Calculate(int x, int y, MathOperation op), який повертає результат.
Виклич його тричі, передаючи логіку через лямбда-вирази:
➕ Для додавання двох чисел.
❌ Для множення двох чисел.
📉 Для знаходження різниці (віднімання).
Тобі не потрібно писати нові методи, просто напиши виклики Calculate(...) з лямбдами в дужках.

✅ Рішення:
Calculate(10, 5, (a, b) => a + b);
Calculate(10, 5, (num1, num2) => num1 * num2); // експериментуємо, чи вийде порахувати, якщо назвати змінні по-іншому (працює)
Calculate(10, 5, (a, b) => a - b);

void Calculate(int x, int y, MathOperation op){
    int result = op(x, y);
    Console.WriteLine($"{result}");
}

delegate int MathOperation(int num1, int num2);

🛠️ Завдання №65.2: Розумний фільтр рядків
Делегат: Створи делегат StringChecker. Він має приймати string і повертати bool.
Метод-виконавець: Створи метод CheckText.
Приймає string text та StringChecker checker.
Якщо checker(text) повертає true, виведи: "Текст пройшов перевірку: [text]".
Інакше виведи: "Текст занадто довгий або некоректний".
Запуск (через лямбди):
Виклич CheckText для слова "Привіт", використовуючи лямбду, яка перевіряє, чи довжина тексту менша за 10 символів (t => t.Length < 10).
Виклич CheckText для того ж слова, використовуючи лямбду, яка перевіряє, чи текст не порожній (t => t != "").

✅ Рішення:
CheckText("Привіт", t => t.Length > 10);
CheckText("Привіт", t => t != "");

void CheckText(string text, StringChecker checker)
{
    bool value = checker(text);
    if(value == true)
    {
        Console.WriteLine($"Текст пройшов перевірку: {text}");
    } else
    {
        Console.WriteLine($"Текст занадто довгий або некоректний");
    }
}

delegate bool StringChecker(string stringName);

🛠️ Завдання №65.3: Складна логіка (Числа)
Тепер працюємо з числами.
delegate: Створи делегат NumberValidator. Він має приймати одне число int і повертати bool.
method: Створи метод ValidateNumber.
Приймає int number та NumberValidator validator.
Важливо: Нехай цей метод сам виводить результат у консоль (void), щоб ми бачили текст у терміналі.
Якщо перевірка пройдена — "Число [x] валідне".
Якщо ні — "Число [x] не пройшло перевірку".
Твоя самостійна робота (Лямбди):
Виклич ValidateNumber для числа 15. Напиши лямбду, яка перевіряє, чи число знаходиться в діапазоні від 10 до 20 одночасно (використовуй &&).
Виклич ValidateNumber для числа -5. Напиши лямбду, яка перевіряє, чи число додатне АБО парне (використовуй ||).

✅ Рішення:
ValidateNumber(15, n => n >=10 && n <= 20);
ValidateNumber(-5, n => n > 0 || n % 2 == 0);

void ValidateNumber(int num, NumberValidator validator)
{
    bool result = validator(num);
    if(result)
    {
        Console.WriteLine($"Число {num} валідне");
    } else
    {
        Console.WriteLine($"Число {num} не пройшло перевірку");
    }
}

delegate bool NumberValidator(int number);

🧩 Завдання №65.4: Смарт-конвертер (Smart Converter)
Уяви, що ти пишеш систему для обробки повідомлень. Користувач вводить текст і число, а програма має обробити їх за певним правилом.
Delegate: Створи делегат DataProcessor. Він має приймати string (текст) та int (кількість повторень) і повертати змінений string.
Method: Створи метод DisplayResult.
Приймає string message, int count та делегат DataProcessor processor.
Метод має викликати processor(message, count) і вивести результат у консоль.
Лямбди:
Перший виклик: Передай лямбду, яка просто повторює рядок вказану кількість разів. (Наприклад: "Hi", 3 -> "HiHiHi"). 
Підказка: 🔛 У C# є "хитрий" спосіб повторити рядок без циклу for — клас StringBuilder або метод string.Concat:
DisplayResult("Text", 6, (m, c) => string.Concat(Enumerable.Repeat(m, c)));
(Тут ми кажемо: повтори "m" "c" разів і з'єднай усе в один рядок).
Другий виклик: Передай лямбду, яка повертає рядок, де вказано довжину тексту, помножену на число. (Наприклад: "Hello", 2 -> "Результат обчислення: 10").

✅ Рішення:
DisplayResult("Text", 6, (m, c) => string.Concat(Enumerable.Repeat(m, c))); // Enumerable.Repeat - це статичний метод, який генерує послідовність (колекцію)

DisplayResult("Hello", 2, (m, c) =>
{
    int result = m.Length * c;
    return $"Результат обчислення: {result}";
});


void DisplayResult(string message, int count, DataProcessor processor)
{
    string result = processor(message, count);
    Console.WriteLine($"{result}");
}

delegate string DataProcessor(string text, int repeat);

🛠️ Завдання №65.5: Система контролю швидкості (Speed Control)
Уяви, що ти розробляєш систему для поліції, яка перевіряє автомобілі на порушення.
Клас Car: Створи клас Car, який має дві властивості: string Model та int Speed.
Делегат CarChecker: Створи делегат, який приймає об'єкт класу Car і повертає bool.
Виконавець (Method): Створи метод AuditCar.
Приймає Car car та CarChecker checker.
Якщо перевірка пройшла (true), виводить: "Авто [Model] ([Speed] км/год) — Порушень не виявлено".
Якщо ні — "Авто [Model] ([Speed] км/год) — УВАГА! Порушення".
Твоя самостійна робота (Лямбди):
Створи об'єкт: new Car { Model = "BMW", Speed = 150 }.
Виклич AuditCar для цього авто, написавши лямбду, яка перевіряє, чи швидкість не перевищує 120 км/год.
Створи другий об'єкт: new Car { Model = "Lanos", Speed = 60 }.
Виклич AuditCar для нього, написавши лямбду, яка перевіряє, чи швидкість більша за 40 км/год (щоб не створювати заторів).

✅ Рішення:
Car bmw = new Car { Model = "BMW", Speed = 150 };
AuditCar(bmw, c => c.Speed <= 120);
Car lanos = new Car { Model = "Lanos", Speed = 60 };
AuditCar(lanos, c => c.Speed > 40);

void AuditCar(Car car, CarChecker checker)
{
    bool result = checker(car);
    if (result)
    {
        Console.WriteLine($"Авто {car.Model} ({car.Speed} км/год) — Порушень не виявлено");
    } else Console.WriteLine($"Авто {car.Model} ({car.Speed} км/год) — УВАГА! Порушення");
}

class Car
{
    public string Model { get; set; } = "";
    public int Speed { get; set; }
}

delegate bool CarChecker(Car car);
