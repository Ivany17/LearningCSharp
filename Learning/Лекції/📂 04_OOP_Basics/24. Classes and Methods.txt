🚗 Клас — це як креслення або категорія (наприклад, "Машина").
🛞 Метод — це конкретна дія, яку може виконувати об'єкт (наприклад, "Завести двигун").

🔑 В C# методи виглядають так:
static void SayHello() 
{
    Console.WriteLine("Привіт із методу!");
}

static void — поки що просто запам'ятай це як "запускну команду".
SayHello — назва дії (пишемо з великої літери).
() — тут можуть бути додаткові дані (аргументи).

‼️ Важливо: щоб метод спрацював, його треба викликати за назвою: SayHello();

У C# є спеціальна команда для зміни кольору тексту:
Console.ForegroundColor = ConsoleColor.НазваКольору;
Наприклад:
🔴 ConsoleColor.Red — червоний.
🟢 ConsoleColor.Green — зелений.
🟡 ConsoleColor.Yellow — жовтий.
⚪️ ConsoleColor.ResetColor() — повертає стандартний колір (білий).

📝 Завдання №24:
Давай створимо твій перший власний метод!
Створи метод з назвою ShowAlert.
Всередині методу напиши код, який виводить: "УВАГА! Це повідомлення з окремого методу!".
Виклич цей метод тричі поспіль у головній частині програми і зафарбуй її червоним кольором.

✅ Рішення:
//(дія друга) над створеним методом викликаємо цей метод
ShowAlert();
ShowAlert();
ShowAlert();

//(дія перша) спочатку створюємо метод
static void ShowAlert()
{
    Console.ForegroundColor = ConsoleColor.Red; // Вмикаємо червоний
    Console.WriteLine("УВАГА! Це повідомлення з окремого методу!");
    Console.ResetColor(); // Повертаємо білий, як було
}
