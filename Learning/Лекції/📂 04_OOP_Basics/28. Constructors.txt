Тема №28: Конструктори (Constructors) 🏗️
Зараз, щоб створити гравця, тобі доводиться писати три рядки коду: створювати об'єкт, 
а потім окремо вписувати ім'я та рівень. Це не дуже зручно, якщо у грі сотні персонажів.

Конструктор — це спеціальний метод всередині класу, який спрацьовує автоматично в момент створення об'єкта (new). 
Він дозволяє «заповнити» характеристики об'єкта одразу.

🔑 Як це виглядає в класі:
class Player
{
    public string nickname;
    public int level;

    // Це конструктор
    public Player(string name, int lvl)
    {
        nickname = name;
        level = lvl;
    }
}

‼️ Тепер створити гравця можна одним коротким рядком:
Player myPlayer = new Player("IvanY1", 10);

📝 Завдання №28:
Давай оновимо твій клас, щоб він став професійнішим.
Додай у свій class Player конструктор, як у прикладі вище.
У верхній частині програми видали старі три рядки створення гравця.
Створи об'єкт одним рядком, передавши ім'я та рівень прямо в дужки new Player(...).
Виведи результат у консоль, щоб переконатися, що все працює.

✅ Рішення:
Player myPlayer = new Player("IvanY1", 10);
Console.WriteLine($"Гравець: {myPlayer.nickname}, Рівень: {myPlayer.level}");

class Player
{
    public string nickname = "NoName";
    public int level;
    public Player(string userName, int userLevel)
    {
        nickname = userName;
        level = userLevel;
    }
}
