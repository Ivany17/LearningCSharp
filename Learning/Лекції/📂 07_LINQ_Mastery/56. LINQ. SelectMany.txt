Тема №56. LINQ: "Розгладжування" списків (SelectMany)
Теорія:
Бувають ситуації, коли у кожного об'єкта в списку є свій власний список (наприклад, у кожної квартири є 
список мешканців або список показань лічильника). Якщо ти просто використаєш .Select(), ти отримаєш "список списків", з яким незручно працювати.

Метод .SelectMany() "розгладжує" (flatten) ці вкладені колекції в один загальний довгий список.

📝 Завдання №56: "Єдиний реєстр показників"
Давай трохи ускладнимо твій клас Apartment, щоб спробувати цей метод у дії.
Онови клас: Додай властивість public List<double> MonthlyEnergyBill { get; set; } = new List<double>();.
Наповни дані: Додай кожній квартирі у списку buildings по 2-3 цифри (наприклад, показники за січень, лютий, березень).
Застосуй SelectMany: Створи запит, який збере всі показники з усіх квартир в один загальний список allBills.
Порахуй результат: Використай .Average(), щоб дізнатися середній показник по всій мережі за всі місяці.

// // 🟢3️⃣. SelectMany: Глибоке розгортання (Deep SelectMany)
// 📝 Завдання №46.3: "Глибока перевірка обладнання"
// Давай застосуємо цю "трирівневу" логіку до твого проекту.

// Умова:
// У кожній квартирі (Apartment) є список кімнат.
// У кожній кімнаті є список приладів (електроніки).
// Твоє завдання:
// Додай public class Room, де є string Name і List<Device> Devices і додай public class Device, де є string Name
// Додай у клас Apartment:
// public List<Room> Rooms { get; set; } = new List<Room>();
// Обов'язково створи в Main нові ккімнати і наповни їх електронікою
// Використай два SelectMany підряд, щоб дістатися до приладів, зберігаючи при цьому City та Number квартири.

var electronicInApartment = buildings
                        .SelectMany(b => b.Rooms, (buildings, rooms) => new {buildings.City, buildings.Number, rooms})
                        .SelectMany(level1 => level1.rooms.Devices, (level1, device) => new
                                                                {
                                                                    level1.City,
                                                                    level1.Number,
                                                                    NameOfTheRoom = level1.rooms.RoomName,
                                                                    NameOfTheDevice = device.DeviceName
                                                                })
                                                                // 1. Групуємо все, що ми розгорнули, назад за спільними ознаками
                                                                .GroupBy(x => new { x.City, x.Number, x.NameOfTheRoom })
                                                                // 2. Створюємо фінальний вигляд, де прилади йдуть через кому
                                                                .Select(g => new 
                                                                {
                                                                    g.Key.City,
                                                                    g.Key.Number,
                                                                    g.Key.NameOfTheRoom,
                                                                    AllDevices = string.Join(", ", g.Select(d => d.NameOfTheDevice))
                                                                });

foreach(var devices in electronicInApartment)
{
    Console.WriteLine($"Місто: {devices.City} | Кв. №{devices.Number} | Кімната: {devices.NameOfTheRoom} | Прилади: {devices.AllDevices}");
    // Місто: Novara | Кв. №12 | Кімната: Кухня | Прилади: Холодильник
    // Місто: Biela | Кв. №34 | Кімната: Ванна кімната | Прилади: Фен, Пральна машина

}
