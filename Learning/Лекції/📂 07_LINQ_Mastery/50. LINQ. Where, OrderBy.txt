Тема №50. LINQ: Фільтрація та сортування даних
Теорія:
LINQ (Language Integrated Query) — це технологія, яка дозволяє писати запити до масивів, списків та інших колекцій 
так само легко, як ми пишемо звичайні речення. Замість довгих циклів foreach та перевірок if, ми використовуємо лаконічні методи-ланцюжки.

Для роботи необхідно підключити простір імен:
using System.Linq;

Найвживаніші методи:
.Where() — фільтрує колекцію. Залишає лише ті елементи, які відповідають вашій умові (наприклад, рівень > 10).
.OrderBy() — сортує елементи за зростанням (від меншого до більшого).
.OrderByDescending() — сортує елементи за спаданням (від більшого до меншого).
.ToList() — перетворює результат запиту назад у звичайний список List<T>.

А в майбутньому тобі знадобляться:
.Select(s => ...) (Проекція/Трансформація) — «витягує» конкретну властивість (наприклад, тільки імена) або змінює тип даних у ланцюжку.
.Average(s => ...) (Агрегація) — обчислює середнє арифметичне числове значення для всього списку.
.Sum(p => p.InStock) - рахує загальну суму	
.Any(condition) — повертає true або false. Відповідає на питання: "Чи є в списку хоча б один елемент, що відповідає умові?". (Наприклад, чи є взагалі ноутбуки в магазині?).
.All(condition) — на відміну від .Any(), цей метод перевіряє, чи ВСІ елементи відповідають умові. (Наприклад: "Чи всі товари в наявності?").
.Contains(значення) - чи є в списку конкретне значення? (Працює без лямбда-виразу, просто шукає точний збіг).
Any + Contains: Це ідеальний спосіб шукати підрядок у списку.
.Count(condition) — рахує кількість елементів (не суму значень всередині них, а просто кількість штук у списку).
.Min() / .Max() — знаходить найменше/найбільше значення.
.GroupBy() — цей метод розбиває твій список на окремі «кошики» за певною ознакою (в нашому випадку — за категорією).

1. Пошук Мінімуму та Максимуму (новинки C#)
.MaxBy(x => x.Prop) — повертає весь об'єкт, у якого значення властивості найбільше.
.MinBy(x => x.Prop) — повертає весь об'єкт, у якого значення властивості найменше.
(На відміну від Max/Min, які повертають лише саме число).

2. Безпечний пошук елементів
.First() / Last() — повертає перший/останній елемент. Викидає помилку, якщо список порожній.
.FirstOrDefault() / LastOrDefault() — повертає перший/останній елемент або null (для об'єктів) / 0 (для чисел), якщо нічого не знайдено.
.Single() — повертає єдиний елемент. Викидає помилку, якщо елементів 0 або більше ніж 1.
.SingleOrDefault() — повертає один елемент або null. Викидає помилку, якщо знайдено 2 і більше елементів.

3. Пагінація (керування кількістю)
.Skip(n) — ігнорує перші n елементів.
.Take(n) — бере тільки перші n елементів, решту відкидає.

4. Робота з множинами (Set Operations)
.Distinct() — видаляє всі дублікати, залишаючи лише унікальні значення.
.Union(otherList) — об'єднує два списки в один і автоматично видаляє дублікати (математичне об'єднання).
.Except(otherList) — «різниця». Залишає елементи, яких немає в іншому списку.
.Intersect(otherList) — «перетин». Залишає тільки ті елементи, які є в обох списках одночасно.

5. Об'єднання списків (Joins):
.Join() та .GroupJoin(): Це коли у тебе є два списки (наприклад, Products і Categories), і тобі треба їх "склеїти" за спільним ID. 
string.Join(separator, collection) — ідеальний спосіб перетворити список назв на один рядок для виводу в консоль.
Тобто string words = string.Join(", ", group.Select(g => g.LetterName));

6. Складні вибірки:
.SelectMany(): "Розплющування" списків. Наприклад, якщо у кожного гаджета є список відгуків, і ти хочеш отримати один загальний список усіх відгуків усіх товарів.

7. Перетворення типів, Агрегація та Словники
.Aggregate — «швейцарський ніж» для згортання списку в один результат (число, рядок або складний об'єкт на кшталт Dictionary).
.ToDictionary — перетворити список у "словник" (ключ-значення) для миттєвого пошуку (Key/Value).
.OfType<T>(): Відфільтрувати зі списку об'єкти лише певного типу.

Тобі потрібно створити нову структуру даних, яка імітує реальну базу апартаментів.

1. Створи клас Apartment
Він повинен мати такі властивості:
Number (int) — номер квартири (наприклад, 1 для Novara, 2 для Novi Ligure) [cite: 2026-02-23].
City (string) — місто.
EnergyConsumption (double) — споживання енергії за місяць (кВт·год).
IsOccupied (bool) — чи живуть там зараз люди.

2. Створи список та наповни його
Створи List<Apartment> buildings і додай туди мінімум 5-6 квартир. Обов'язково включи:
Квартиру в місті Novara [cite: 2026-02-23].
Квартиру в місті Novi Ligure [cite: 2026-02-23].
Кілька квартир з високим споживанням (наприклад, > 400 кВт·год) і кілька з низьким.

3. Застосуй LINQ (твоє перше тренування)
Використовуючи методи, які ми обговорили (конспект вище), спробуй вивести в консоль:
Фільтрація: Тільки ті квартири, де споживання більше 100 кВт·год (.Where).
Сортування: Список усіх квартир, відсортований від найнижчого споживання до найвищого (.OrderBy).

        EnergyConsumption = 87.3,
        isOccupied = false
    },
    new Apartment
    {
        Number = 34,
        City = "Biela",
        EnergyConsumption = 110.1,
        isOccupied = false
    },
    new Apartment
    {
        Number = 114,
        City = "Vercelli",
        EnergyConsumption = 90.0,
        isOccupied = true
    },
        new Apartment
    {
        Number = 76,
        City = "Alessandria",
        EnergyConsumption = 56.2,
        isOccupied = false
    },
    new Apartment
    {
        Number = 80,
        City = "Genova",
        EnergyConsumption = 123.4,
        isOccupied = false
    },
    new Apartment
    {
        Number = 114,
        City = "Novi Ligure",
        EnergyConsumption = 156.7,

foreach(var apart in listApartment)

    //Квартира № 34 в місті Biela споживає 110,1 кВт*год

    //Квартира № 114 в місті Novi Ligure споживає 156,7 кВт*год
}

public class Apartment
{
    public int Number { get; set; }
    public string? City { get; set; }
    public double EnergyConsumption { get; set; }
