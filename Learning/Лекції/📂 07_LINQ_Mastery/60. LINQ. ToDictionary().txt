Тема №60. LINQ: Метод .ToDictionary()
Теорія:
Метод .ToDictionary() перетворює колекцію (список або масив) на об'єкт Dictionary<TKey, TValue>. 
Це критично важливо, коли тобі потрібно миттєво знаходити дані за ключем, а не перебирати весь список щоразу.

У цього методу є дві найпопулярніші форми:
З одним аргументом: Ти вказуєш лише те, що буде ключем. Значенням (Value) стане весь об'єкт зі списку.
З двома аргументами: Ти вказуєш, що буде ключем, а що — значенням.

У реальному житті дані часто бувають "брудними" (наприклад, два записи для одного паспорта через помилку оператора). 
Щоб програма не падала, у нас є два основні шляхи.

Шлях 🅰️: Попереднє очищення через .DistinctBy()
Ми просто кажемо LINQ: "Залиш тільки по одному запису для кожного номера паспорта, а решту ігноруй".

var safeDictionary = citizens
    .DistinctBy(c => c.PassportNum) // Залишить першого зустрічного з таким ключем
    .ToDictionary(c => c.PassportNum, c => c.Age);

Шлях 🅱️: Використання .ToLookup() (якщо потрібно зберегти ВСІХ)
Метод ToLookup схожий на словник, але він дозволяє одному ключу мати декілька значень (колекцію). 
Це ніби папка, де лежать усі люди з одним номером паспорта.

var lookup = citizens.ToLookup(c => c.PassportNum);
// Тепер, якщо в списку ключі повторюються для двох людей - lookup["AA123"] поверне колекцію з 2-х людей

⚠️ Важливе правило: Ключі в словнику мусять бути унікальними. Якщо LINQ зустріне два елементи з однаковим ключем, 
програма видасть помилку (ArgumentException).

📝 Завдання №60: "Реєстр паспортів"
Уяви, що ми розробляємо систему для міграційної служби. У нас є список громадян, і нам треба швидко знаходити людину за номером її паспорта.
Твоє завдання:

Використай .ToDictionary(), щоб створити словник, де:
Ключем є номер паспорта (PassportNum).
Значенням є рядок з іменем та віком (наприклад: "Олег Петренко, 25 років").
Виведи результат у консоль через foreach.
Підказка: Використовуй форму з двома лямбда-виразами: citizens.ToDictionary(c => c.PassportNum, c => $"{c.FullName}...").

✅ Рішення:
//У файлі Program.cs
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text.Json;
using System.IO;
using System.Text.RegularExpressions;
using System.Diagnostics;

var citizens = new[]
{
    new { PassportNum = "AA123", FullName = "Олег Петренко", Age = 25 },
    new { PassportNum = "BB456", FullName = "Ганна Коваль", Age = 30 },
    new { PassportNum = "CC789", FullName = "Ігор Сидор", Age = 22 }
};

var toDictionary = citizens.ToDictionary(c => c.PassportNum, c => c); // c => c - якщо треба знайти весь масив | c => c.Age - якщо треба знайти щось конкретне (Age)
var passNum1 = toDictionary["AA123"];
var passNum2 = toDictionary["BB456"];
var passNum3 = toDictionary["CC789"];
Console.WriteLine($"{passNum1.FullName}, {passNum1.Age} років"); // Олег Петренко, 25 років
Console.WriteLine($"{passNum2.FullName}, {passNum2.Age} років"); // Ганна Коваль, 30 років
Console.WriteLine($"{passNum3.FullName}, {passNum3.Age} років"); // Ігор Сидор, 22 років

Крок №2: "Анонімні типи та трансформація"
Давай спробуємо другий варіант, де ми формуємо значення (Value) прямо всередині методу.

Завдання:
Використовуй той самий масив citizens.
Створи словник ageRegistry, де:
Ключ: PassportNum.

Значення: Тільки вік людини (int).
Після створення словника виведи в консоль вік Ганни Коваль, звернувшись до словника за її ключем (BB456).
Навіщо це в довіднику: Це показує, як економити пам'ять, зберігаючи в словнику лише ті дані, 
які нам дійсно потрібні для швидкого пошуку, а не весь об'єкт.

✅ Рішення:
var toDictionary = citizens.ToDictionary(c => c.PassportNum, c => c.Age); // c => c - якщо треба знайти весь масив | c => c.Age - якщо треба знайти щось конкретне (Age)
var passNum2 = toDictionary["BB456"];

Console.WriteLine($"{passNum2} років"); // 30 років
