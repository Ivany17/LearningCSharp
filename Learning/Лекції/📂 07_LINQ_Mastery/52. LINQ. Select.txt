Тема №52. LINQ: Перетворення даних (Select)
Метод .Select() дозволяє "трансформувати" об'єкти. Наприклад, якщо у тебе є список цілих об'єктів Apartment, 
але для звіту тобі потрібні лише їхні номери або тільки назви міст, .Select() витягне саме ці поля і створить новий список.
Якщо Where — це сито (фільтр), то Select — це дзеркало або конвеєр. Він бере кожен елемент і «перетворює» його на щось інше.

📝 Завдання №52: "Список адрес"
Уяви, що тобі потрібно роздрукувати список міст, де знаходяться твої об'єкти, щоб передати його кур'єру.
Використай свій список buildings.
Застосуй .Select(a => a.City).
Оскільки у списку можуть бути однакові міста, додай метод .Distinct() (він видаляє дублікати, залишаючи тільки унікальні назви).
Виведи результат у консоль через foreach.

Приклад коду для конспекту:
var cities = buildings.Select(a => a.City).Distinct().ToList();

🚀 Завдання №52.2: «Система керування запасами»
Уяви, що ти працюєш над модулем для складу. У тебе є список ваги товарів у грамах, але для логістики потрібні зовсім інші дані.
List<int> inventoryInGrams = new List<int> { 500, 1200, 350, 4000, 2100, 900, 5000, 150 };
Твоє завдання:
Переведи всю вагу з грамів у кілограми (пам'ятай, що в 1 кг — 1000 грамів, і результат має бути дробовим числом double, 
щоб не втратити точність).
Складська техніка може підняти тільки важкі вантажі, тому відфільтруй отриманий список так, щоб залишилися тільки ті позиції,
вага яких 2 кілограми або більше.
Знайди середню вагу саме цих важких вантажів.
Виведи в консоль:
Список важких вантажів у кг (через foreach).
Середню вагу (окремим рядком).

✅ Рішення:
//У файлі Program.cs
using System;
using System.Collections.Generic;
using System.Linq;

List<int> inventoryInGrams = new List<int> { 500, 1200, 350, 4000, 2100, 900, 5000, 150 };
var inventoryInKilograms = inventoryInGrams.Select(i => i / 1000.0);
var heavyPackages = inventoryInKilograms.Where(i => i > 2);
var averageHeavy = heavyPackages.Average();
foreach(var heavy in heavyPackages)
{
    Console.Write(heavy + " кг, ");
}
Console.WriteLine();
Console.WriteLine($"Середня вага важких товарів: {Math.Round(averageHeavy)} кг");
