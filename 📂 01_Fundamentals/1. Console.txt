Тема №1: Що таке C# і як змусити комп'ютер "говорити"? 🤖

Уяви, що комп'ютер — це дуже слухняний робот, який розуміє лише спеціальні команди. C# (вимовляється як "Сі Шарп") — 
це мова, якою ми пишемо ці команди.

Найперша програма, яку пише кожен програміст, називається "Hello World" (Привіт, світу). Її мета — просто вивести текст на екран.
Щоб комп'ютер щось надрукував, ми використовуємо команду:

Console.WriteLine("Твій текст");

Console — це вікно (термінал), де ми бачимо результат.
WriteLine — команда "напиши рядок".
"..." — текст, який ми хочемо показати, обов'язково береться в лапки.
; — крапка з комою в кінці команди. Це як крапка в кінці речення, вона каже комп'ютеру: "Ця команда закінчена".

📝 Завдання №1:
Відкрий VS Code, створи новий проект (або файл Program.cs) і напиши код, який виведе на екран фразу:
Я починаю вивчати C#!

✅ Рішення:
Console.WriteLine("Я починаю вивчати C#!");

// Налаштування для коректної роботи кирилиці
Console.OutputEncoding = Encoding.UTF8;
Console.InputEncoding = Encoding.UTF8;


// Фарбуємо наше повідомлення у різні кольори
Console.ForegroundColor = ConsoleColor.Blue; // Вмикаємо синій колір 🔵
Console.WriteLine("Привіт, C#!");            // Друкуємо текст
Console.ResetColor();                        // Повертаємо звичайний колір (білий) ⚪
