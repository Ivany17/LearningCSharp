Тема №2: Змінні та типи даних (Наші комірки для зберігання) 📦
Уяви, що комп'ютер має величезну кількість порожніх коробок. Щоб щось зберегти, нам потрібно взяти коробку, дати їй назву і покласти туди щось. 
У програмуванні ці коробки називаються змінними.
Але є одне правило: кожна коробка має свій «тип». Ми не можемо покласти текст у коробку для чисел, і навпаки.

Сьогодні ми вивчимо два найголовніші типи:

string (рядок) — для тексту. Будь-яке слово або речення. Текст завжди пишемо в лапках: "Привіт".
int (ціле число) — для цілих чисел (без комах). Наприклад: 5, 100, -20. Числа пишуться БЕЗ лапок.

⚠️ Як створити таку «коробку» (змінну):
Спершу пишемо тип, потім назву, а потім кладемо туди значення.

string myName = "Іван"; — ми створили коробку для тексту з назвою myName і поклали туди "Іван".
int myAge = 25; — ми створили коробку для чисел з назвою myAge і поклали туди 25.

Щоб вивести вміст коробки на екран, ми просто пишемо її назву всередині Console.WriteLine():
Console.WriteLine(myName); — комп'ютер подивиться, що лежить у коробці myName, і надрукує "Іван".

📝 Завдання №2:
Створи програму, у якій:
Створи змінну типу string з назвою city і запиши туди назву свого міста (наприклад, "Київ").
Створи змінну типу int з назвою year і запиши туди поточний рік (2026).
Виведи ці дані в термінал за допомогою двох команд Console.WriteLine.

✅ Рішення:
string city = "Київ";
int year = 2026;
Console.WriteLine(city);
Console.WriteLine(year);
